title: "# Multi-Agent Delegation & Handoffs"
description: Stop copy-pasting between windows—type # to hand off parallel tasks, or @-mention another session so a new Agent can pick up right where it left off.
---

Every coding Agent has its sweet spot: one might excel at multi-file refactors, another at fast debugging, another at searching fresh web discussions, and another at strict code review.

Instead of acting as a human clipboard copying outputs from one window into another, CodexHost lets **Agents collaborate and hand off work directly**.

---

## 1. Type `#` to Delegate Parallel Subtasks

In any supported chat composer, type `#`, pick an Agent from the menu, and describe a self-contained task:

```text
Have #claude-code review this diff independently and flag any backwards-compatibility risks.

Have #pi track down why this unit test fails intermittently.

Have #omp implement the API endpoint while I finish wiring up the frontend form.
```

By default, the new task uses that Agent's default model, or you can ask for a specific model / Thinking level in your prompt.

### What Happens Next?

1. **A real session appears in your sidebar**: Each delegated task spins up a genuine, independent session in the target Agent and runs in parallel without blocking your current chat.
2. **Open or step in anytime**: Nothing happens in a black box—click the child session at any point to watch tool calls, review diffs, or send follow-up instructions yourself.
3. **Automatic completion report**: As soon as the child session finishes, your main session receives a completion notice and can read the final findings automatically.

---

## 2. `@`-Mention (or Drag In) Another Session to Pass the Baton

What if **one Agent hits its quota mid-task**, or you finished researching a bug with Grok and now want Pi or Claude Code to write the fix?

1. Start a session with the new Agent;
2. Type `@` in the composer to search for the previous session (or simply **drag that session from the left sidebar straight into the input box**);
3. Tell the new Agent:

```text
Check how far this session got, pick up the context, and finish the remaining work.
```

The current Agent can read the referenced session's history directly—and even send follow-up instructions to it—without you copying a single line of text.

---

## Bonus: Keep Parallel Code Edits Isolated with Git Worktrees

When multiple Agents need to edit code in the same repository at the same time, programmatic delegation via CLI or MCP supports `--worktree <branch-name>`—automatically giving each Agent its own isolated `.worktrees/` checkout so they never overwrite each other's files.

Want to trigger delegation from terminal scripts, Claude Desktop, or custom bots? Head over to **[CLI, MCP & HTTP Overview](/en/docs/platform/interfaces)**.
