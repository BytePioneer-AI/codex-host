Want an Agent to run a task on a regular schedule—say checking overnight commits at 9 AM, running a test suite check, or summarizing open work? CodexHost extends Codex Desktop's built-in scheduler so you can assign scheduled tasks to **external Agents, their models, and a specific local project folder**.

## How to Set One Up

1. In Codex Desktop, open **codexhost Settings → Scheduled Tasks** to jump straight to the Automations view, then create a new task.
2. Under **Advanced settings**, make sure **"Run on this computer"** is turned **on** and **"Start a new chat each time"** is turned **off**.
3. Pick your desired **Agent** (Claude Code, Pi, Grok, etc.), **Model**, and **Workspace** (local project folder, or leave on automatic assignment).
4. Set your schedule and prompt, then save.

## Good to Know

- **Local pinned-chat mode only**: External Agents work with personal, local, pinned-chat schedules (reusing one persistent session). Cloud schedules, team automations, and new-chat-per-run schedules remain Codex-only.
- **Agent icons in the sidebar**: Scheduled tasks bound to an external Agent show that Agent's icon right next to the title in the sidebar so you can tell at a glance who runs what.
- **Keep Codex Desktop open**: Scheduled runs are triggered by Codex Desktop itself—tasks won't fire while your computer is asleep or Codex Desktop is quit.
