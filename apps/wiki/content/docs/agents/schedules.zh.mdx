---
title: 定时任务（Schedules）
description: 让指定的外部 Agent 按固定时间在本地项目里自动干活，比如每日巡检、跑测试或整理日报。
---

如果你想让某个 Agent 每天固定时间自动帮你干点活（比如每天早上 9 点检查仓库最新提交、跑一遍测试摘要或汇总待办），可以直接在 Codex Desktop 里配置**定时任务**。

CodexHost 在官方定时任务弹窗里加上了 **Agent 选择、模型选择和本地项目目录绑定**。

## 怎么创建一个外部 Agent 定时任务？

1. 在 Codex Desktop 里打开 **「codexhost 设置 → 定时任务」**，会自动跳转到任务管理页，点击新建任务；
2. 先点开弹窗里的「高级设置」，确认开启 **「在此电脑上运行」**，并关闭 **「每次运行都开启新聊天」**；
3. 这时弹窗上方就可以自由选择你想用的 **Agent**（如 Claude Code、Pi、Grok 等）、对应的 **模型**，以及要绑定的 **本地工作区（项目文件夹）**；
4. 填好执行时间和任务提示词，点保存即可。

## 使用时需要注意什么？

- **仅限「本机固定对话」模式**：外部 Agent 目前只支持在你的电脑本机、固定复用同一个聊天会话运行的个人任务。云端运行、团队任务或“每次新建聊天”模式仍只支持官方 Codex。
- **侧边栏一眼区分是谁的活**：创建好之后，左侧定时任务列表里会在任务标题旁边显示对应 Agent 的图标，一眼就能看清哪个任务归哪个 Agent 管。
- **电脑和桌面端要开着**：定时任务由正在运行的 Codex Desktop 按点触发；如果到点时电脑关机休眠、或者 Codex Desktop 彻底退出了，期间是不会执行的。
