If you use multiple AI coding tools—say Claude Code for heavy refactors, Pi for quick edits, Grok for fresh web context, and Codex for code review—switching windows and copying context back and forth gets old fast.

**CodexHost brings 15+ Agents into one place**: run **Claude Code, Pi, OpenCode, Grok, DSH, Antigravity**, and more right inside the official **Codex Desktop** app (or the lightweight **Web app**).

Every Agent runs as its own session in the sidebar with the same **Diff review panel, message Forking, and tool approvals** you already know—plus inline `#` delegation so Agents can hand off work to each other.
