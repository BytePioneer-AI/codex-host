平时写代码，你可能同时装了好几个 AI 编程工具：用 Claude Code 改复杂模块、用 Pi 快速跑小任务、用 Grok 查最新资料，再加上官方 Codex 审代码。来回切终端、复制粘贴上下文非常折腾。

**CodexHost 做的事情很简单**：把 **Claude Code、Pi、OpenCode、Grok、DSH、Antigravity** 等 15+ 个 Agent 直接放进你熟悉的 **Codex Desktop**（以及更省内存的 **Web 网页端**）里。

每个 Agent 都是左侧列表里的一个独立对话，你可以像用原生 Codex 一样**看代码改动（Diff）、从任意消息分叉重试（Fork）、点工具审批**，甚至在输入框里敲个 `#` 让它们互相派活。
