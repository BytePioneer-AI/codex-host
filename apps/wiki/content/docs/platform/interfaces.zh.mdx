除了在界面里手打字聊天，CodexHost 本身还是一个**能被任何外部程序调用的本机多 Agent 调度中心**。

只要你电脑上的 CodexHost 正在运行（开着桌面端或跑了 `codexhost web`），你写的 **终端自动化脚本、本地定时脚本、Claude Desktop / Cursor，或者常驻的飞书 / Slack / Telegram 机器人**，都可以直接喊电脑上的任意 Agent 去干活、等结果、继续追问。

## 最省心的一点：外部派的活，界面里全都看得见

很多命令行自动化工具一跑起来就是“黑盒”，卡住了都不知道在干嘛。而在 CodexHost 里：

- **全程可视、随时接手**：不管你是从脚本、MCP 还是机器人派出的任务，都会**立刻出现在桌面端和网页端的左侧会话列表里**。你想什么时候点开看进度、帮忙点个审批、或者手工插两句话接管都行。
- **自动切独立 Git 分支目录**：支持一键拉起独立的 Git Worktree（`--worktree`），同时派 5 个 Agent 改同一个项目也不会把文件改乱。
- **支持半路插话或叫停**：Agent 正在跑的时候，外部程序依然可以给它递话微调方向（`steer`），或者直接叫停重发新指令（`interrupt`）。
- **不怕漏掉完成通知**：支持注册完成提醒（`watch`），哪怕你的机器人中途重启过，也能从本地事件记录里补读任务结果。
