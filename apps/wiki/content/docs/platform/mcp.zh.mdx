---
title: 接入 Claude Desktop / Cursor 等 MCP 客户端
description: 把 CodexHost 挂载成 MCP 服务，让你在 Claude Desktop、Claude Code 或 Cursor 里直接指挥本机所有 Agent 干活。
---

如果你平时主力在用 **Claude Desktop、Claude Code** 或 **Cursor**，可以通过标准 **MCP（Model Context Protocol）** 把本机的 CodexHost 挂上去——这样你在 Claude Desktop 里聊着天，就能顺口让它喊本机的 **Pi、Grok 或 OpenCode** 去跑测试、查资料或并行改代码。

---

## 第 1 步：生成一个专属访问令牌

和免配置的终端命令行不同，外部客户端通过 MCP 连接时需要先登记一个名字、领一把专属令牌（名字只能用小写字母、数字和连字符 `-`）：

```bash
codexhost client add claude-desktop
```

终端会打印出一串以 `chc_` 开头的令牌。**这串令牌只会显示这一次，请立刻复制保存好。**

> 以后想查看登记过哪些客户端，运行 `codexhost client list`；想立刻作废某个令牌，运行 `codexhost client remove claude-desktop`。

---

## 第 2 步：配置到你的 AI 客户端

CodexHost 默认在本机 `http://127.0.0.1:4398/mcp` 提供 MCP 服务（请保持 Codex Desktop 或 `codexhost web` 在后台运行）。把下面示例里的 `<你的令牌>` 换成刚才拿到的 `chc_...` 即可：

### 接入 Claude Code（一行命令搞定）

```bash
claude mcp add --transport http codexhost http://127.0.0.1:4398/mcp \
  --header "Authorization: Bearer <你的令牌>"
```

### 接入 Claude Desktop

注意不要填在 Claude 设置里的“云端自定义连接器”（Anthropic 云端服务器连不到你电脑本机的 `127.0.0.1`）。请打开本机的 `claude_desktop_config.json`，通过 `mcp-remote` 桥接：

```json
{
  "mcpServers": {
    "codexhost": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "http://127.0.0.1:4398/mcp",
        "--header",
        "Authorization:${CODEXHOST_AUTH}"
      ],
      "env": {
        "CODEXHOST_AUTH": "Bearer <你的令牌>"
      }
    }
  }
}
```

保存后重启 Claude Desktop 即可生效。

### 接入其他支持 HTTP MCP 的工具（如 Cursor 等）

直接在客户端的 MCP 配置中填入地址 `http://127.0.0.1:4398/mcp`，并附带请求头 `Authorization: Bearer <你的令牌>`。

---

## 连上之后，AI 能调用哪些能力？

挂载成功后，客户端会自动获得和 CodexHost 命令行完全对齐的一套工具：

- **先摸清家底**：`host_info`（看电脑环境）、`project_list`（找本地 Git 仓库）、`harness_list` / `harness_inspect`（看有哪些 Agent 和模型可用）；
- **派活干活**：`delegate_start`（新建独立子会话派任务，支持 `worktree` 新分支隔离和 `watch` 完成监听）；
- **追问与控制**：`thread_send`（继续发消息、`steer` 插话调整方向、`interrupt` 打断重发）、`thread_cancel`（取消当前轮）；
- **拿结果与读文件**：`thread_wait` / `thread_read`（等待结果或按轮次读对话）、`thread_file_read`（安全读取最终报告里引用的工作区文件）。
