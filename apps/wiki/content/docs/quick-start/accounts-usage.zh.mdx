## Codex 额度用光了，还能继续用其他 Agent 吗？

**完全可以，互不影响。**

平时用官方 Codex Desktop 时，一旦你的 ChatGPT / Codex 订阅额度耗尽，输入框往往会被锁住不让发消息。但在 CodexHost 里：

- 只有官方 Codex 会话受 Codex 额度限制；
- 你随时可以在输入框右下角切换到 **Claude Code、Pi、OpenCode、Grok、DSH** 等外部 Agent 继续发消息干活——它们各自走你自己的对应账号或 API Key，不会被 Codex 的额度拦住。

---

## 在一页里看清各工具的剩余额度

打开 **「codexhost 设置 → 账号」**，你可以在一张表里集中查看本机已登录工具的真实套餐余量或预付费余额：

- 支持展示 **Codex**（5 小时 / 7 天窗口及重置卡到期时间），以及已登录并返回有效额度数据的 **Claude Code、Grok、Cursor、Kimi Code、Qoder、Antigravity、Pi（如 DeepSeek 或支持余额查询的自定义站点）**。
- 可随时切换按 **「剩余」** 或 **「已用」** 百分比查看，并显示距离下次额度重置还有多久。
- **截图防漏隐私**：点一下右上角工具栏里的「眼睛」图标，页面上所有邮箱中间位都会自动打码成 `****`，方便截图发群交流。

> 说明：CodexHost 只读取你在各个工具里已经登录好的账号状态，不会替你保管密码，也不修改官方 Codex 的登录方式。

## 一键把 Codex / Grok 登录态导入给 Pi

如果你电脑上已经登录了官方 **Codex** 或 **Grok**（OAuth 账号），想在轻快的 **Pi** 里直接调用这些模型，不需要去终端里重新配一遍认证：

1. 打开 **「codexhost 设置 → 账号」**；
2. 在 Codex 或 Grok 账号下方点 **「导入到 Pi」**（或在下方「Pi 中的账号」区域点「导入账号」）；
3. 确认入口名称后点确定——**不用重启软件，新开一个 Pi 会话就能直接选用对应的模型**。

以后想更新凭据或移除这个入口，也在同一个区域点一下就能搞定，不会影响你原来的 Codex 或 Grok 登录状态。

## 看清每一轮和每一天花了多少 Token

### 1. 聊天时的实时用量浮窗

在支持用量回报的 Agent 会话里，点击底部状态栏的用量按钮，可以随时看当前对话的实时指标：

- **上下文占用（Context）**：当前对话塞了多少内容，离上下文上限还有多远；
- **缓存命中率（Cache）**：多少 Token 走的是便宜的缓存读取，省了多少钱；
- **首字响应时间（TTFT）** 与 **本轮估算费用**。

### 2. 跨工具全局用量统计

在 **「codexhost 设置 → 用量统计」**（或本地控制台 `codexhost console` 的「用量统计」页）里，可以看到汇总账单：

- 自动扫描并汇总官方 Codex 和各个外部 Agent 的本地会话记录，自动去重；
- 按不同模型、时间和工具统计总 Token 消耗与估算花费趋势，帮你算清主力开销花在哪儿了。
