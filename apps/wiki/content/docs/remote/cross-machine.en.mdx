CodexHost offers three ways to work away from a single screen—**Web App**, **SSH Remote Host**, and **Remote Control**—and they solve very different problems.

Match your situation below:

- **Scenario A: "My code and Agents already run on my main computer—I just want to check or steer them from my phone, tablet, or couch laptop."**
  👉 Use **[Web App & Mobile Access](/en/docs/web/mobile)**. Scan a QR code and you're in—no remote host setup needed.
- **Scenario B: "My codebase, toolchain, and Agent logins live on a remote Linux or macOS dev server, and I want a native UI on my laptop."**
  👉 Use **[SSH Remote Host](/en/docs/remote/ssh)**. Your local Codex Desktop stays snappy while Agents execute on the remote machine.
- **Scenario C: "My code and Agents live on a Windows PC, and I want to drive them from another computer without opening ports or setting up SSH."**
  👉 Use **[Windows Remote Control](/en/docs/remote/remote-control)** with a simple pairing code.
