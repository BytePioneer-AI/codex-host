CodexHost 既有**手机网页端**，又有 **SSH 远程连接**和 **Remote Control**，名字听起来都有点像“远程”，到底该用哪个？

先对号入座看你的真实场景：

- **场景 A：「代码和 Agent 都在我办公桌这台电脑上，我只是离开座位想用手机或平板看看进度」**
  👉 直接用 **[Web 网页端与手机访问](/zh/docs/web/mobile)**，扫码就能进，不需要配任何跨机主机。
- **场景 B：「我手头用笔记本，但真正写代码的项目目录和开发环境全在远程 Linux / Mac 开发机上」**
  👉 用 **[SSH 连接远程服务器](/zh/docs/remote/ssh)**，本地享受丝滑的桌面界面，干活进程全跑在远端服务器。
- **场景 C：「我的代码和 Agent 全装在另一台 Windows 台式机上，我想从手头这台电脑遥控它，又不想折腾内网穿透」**
  👉 用 **[Remote Control 遥控 Windows](/zh/docs/remote/remote-control)**，输个配对码就能连。

| 使用模式                   | 你在哪个屏幕上操作         | Agent 实际跑在哪台机器           | 代码文件和账号凭据在哪      | 操作指南                                            |
| :------------------------- | :------------------------- | :------------------------------- | :-------------------------- | :-------------------------------------------------- |
| **本机桌面端**             | 当前电脑的 Codex Desktop   | 当前电脑                         | 当前电脑                    | [安装与启停](/zh/docs/quick-start/install)          |
| **Web 网页端**             | 手机 / 平板 / 任意浏览器   | **你的主力电脑**（和桌面端共享） | **你的主力电脑**            | [Web 网页端与手机访问](/zh/docs/web/mobile)         |
| **SSH 远程主机**           | 本地电脑的 Codex Desktop   | **远程 Linux / Mac 服务器**      | **远程 Linux / Mac 服务器** | [SSH 连接远程服务器](/zh/docs/remote/ssh)           |
