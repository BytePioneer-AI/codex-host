如果你的主力项目和各种 Agent 环境都配在家里或工位的一台 **Windows 台式机**上，想从手头另一台电脑（比如 Mac 笔记本）直接调用那台 Windows 上的 Agent，又不想折腾内网穿透或 SSH，可以用实验性的 **Remote Control** 模式。

它直接复用了 Codex Desktop 官方自带的 Remote Control 配对通道：

- **不用开任何防火墙或公网端口**；
- **账号和代码绝不外泄**：你的 API Key、Agent 登录态和项目文件全都留在那台 Windows 电脑本地，控制端只是远程发指令和看画面。

---

## 3 步连上你的 Windows 电脑

### 准备工作

- 两台电脑都装好**相同版本**的 CodexHost，并且**两边都必须通过 `codexhost` 命令或图标启动 Codex Desktop**；
- 两边登录好官方 Remote Control 要求的 ChatGPT 账号；
- 想用的外部 Agent（如 Claude Code、Pi、Grok 等）已经在那台 Windows 电脑上装好并能正常用。

### 开始配对连接

1. **在被控的 Windows 电脑上**：打开 Codex Desktop 的 **「设置 → 连接 → 控制此电脑」**，开启访问权限并记下屏幕上的**配对码**；
2. **在你手头的控制端电脑上**：打开 Codex Desktop 的 **「设置 → 连接 → 控制其他设备」**，输入刚才的配对码，选中那台 Windows 环境；
3. **打开项目直接用**：打开 Windows 上的项目目录，在聊天输入框右下角就能直接选那台 Windows 上装好的各个 Agent 了！

---

## 连不上或看不到 Agent 怎么排查？

1. **先测一下官方原生 Codex 能不能跑**：如果连原生的 Codex 任务都发不出去，说明是官方账号配对本身还没通，重新配对一次即可。
2. **确认被控端启动方式**：Windows 上的 Codex Desktop 必须是由 **`codexhost`** 拉起的（如果是直接双击原版 Codex 图标打开的，不会加载外部 Agent 支持——彻底退出后用 `codexhost` 重新打开再试）。
3. **确认两端版本号一致**：如果报错提示找不到接口，把两台电脑都运行 `codexhost update` 升到同一版本并重启即可。

更多说明可查阅仓库中的 [Remote Control 详细文档](https://github.com/BytePioneer-AI/codex-host/blob/main/docs/platforms/remote/remote-control-host.zh-CN.md)。
