title: 连接远程 Mac / Linux 服务器（SSH）
description: 代码和 Agent 都在远程服务器上？用本地 Codex Desktop 连上去直接操作，支持在界面里一键安装远程服务。
---

如果你的项目代码、编译环境和已登录的 Claude Code / Pi 等工具都在一台**远程 Linux 或 Mac 开发机**上，通过 SSH 模式，你可以**在手头电脑的 Codex Desktop 里顺滑聊天、看 Diff、点审批，而真正的 Agent 进程全在远程服务器上跑**。

## 开始前确认三件事

1. **手头这台电脑**：支持 macOS / Windows / Linux，已经通过 `codexhost` 启动了 Codex Desktop。
2. **远程服务器**：必须是 **Linux 或 macOS**（不支持把 Windows 当作 SSH 被控端），已安装 **Node.js 22.19+ 或 24**、npm 和官方 Codex CLI，并且你想用的 Agent（如 Claude Code、Pi 等）已经在那台机器上装好并登录完毕。
3. **SSH 能免密连通**：先在本地终端手动 `ssh 用户名@服务器地址` 试登一次，确认配好了 SSH 密钥或 SSH Config 别名（连接界面不会弹密码输入框）。

---

## 推荐方式：在设置界面里一键安装并连接

不需要自己去远程服务器上敲一堆安装命令，直接在界面里点几下就能搞定：

1. 在本地电脑打开 **「codexhost 设置 → 远程连接」**，点击 **「添加连接」**（如果你之前已经在官方「设置 → 连接 → SSH」里加过这台服务器，它会自动出现在列表里，不用重复添）；
2. 填一个好认的名称（比如「公司开发机」）和 SSH 地址（如 `dev@192.168.1.50` 或你的 SSH 别名），点 **「保存」**；
3. 页面会自动检测这台服务器——如果还没装远程服务，直接点击 **「安装并连接」**，等它自动装上和你本机一致的版本；
4. 显示 **「已连接」** 后，在 Codex Desktop 里打开这台远程服务器上的项目文件夹，就能在输入框右下角直接选远端服务器上的 Agent 开工了！

> 以后升级了本地的 CodexHost，也只需要回到「远程连接」页面点一下 **「更新到本机版本」** 即可同步升级远端。

## 备选方式：手动在远程服务器上用命令行安装

如果你更习惯自己登录服务器敲命令（或者需要排查故障），确保两端版本一致后，在远程服务器上依次运行：

```bash
npm install -g @codexhost/cli
codexhost remote install
codexhost remote start
codexhost remote status
```

### 远程机器是 Mac，读不到钥匙串里的登录凭据怎么办？

默认情况下，SSH 会话可能读不到远程 Mac 桌面钥匙串里的登录态（比如调 `gh` 或部分桌面授权工具时报错）。只要远程 Mac 当前保持着同一个用户的桌面登录状态，可以在远程 Mac 上切换为桌面会话模式：

```bash
codexhost remote stop
codexhost remote install --session desktop
codexhost remote start
```

更多远程维护与排障细节，可参考仓库中的 [SSH 远程完整教程](https://github.com/BytePioneer-AI/codex-host/blob/main/docs/platforms/remote/remote-ssh-host.zh-CN.md)。
