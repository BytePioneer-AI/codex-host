CodexHost 自带一套独立的 **Web 网页端**。它的界面和桌面端保持一致，连的是电脑上同一个后台，但**浏览器占用的内存比桌面客户端少得多**。

更重要的是：只要你的电脑开着，出门在外拿手机、平板或另一台轻薄本打开浏览器，就能随时看任务进度、点工具审批、继续发消息。

## 第 1 步：在电脑上启动网页端

```bash
codexhost web
```

运行后会在后台启动服务（默认本机地址 `http://127.0.0.1:4400`），并自动弹出浏览器页面。

> **放手关窗口就行**：启动成功后，就算你把刚才的终端关掉、或者把浏览器标签页关掉，后台服务和正在跑的 Agent 任务都**不会停**。真的想全部关掉时，运行 `codexhost stop`。

---

## 第 2 步：让手机或其他设备连进来

在电脑浏览器里打开 Web 端，点击左侧栏的 **「远程访问」**（或者进「设置 → 连接设备」），选一种连接方式后，直接用手机相机扫屏幕上的二维码就能进：

| 连接方式                    | 什么时候选它？                                    |          安全加密           | 你需要准备什么                                                                    |
| :-------------------------- | :------------------------------------------------ | :-------------------------: | :-------------------------------------------------------------------------------- |
| **官方加密中转（推荐）**    | 人在外面跨网络连家里/公司电脑，手机不想装任何 App | HTTPS（在你的电脑上才解密） | 不用准备，点「启用中转」即可用                                                    |
| **Tailscale HTTPS（推荐）** | 长期跨网络用，只允许你自己的设备访问              |            HTTPS            | 电脑和手机都装好 Tailscale                                                        |
| **同一 Wi-Fi**              | 在家或办公室连同一个路由器，临时扫一下最快        |          明文 HTTP          | 手机和电脑连同一个可信 Wi-Fi                                                      |
| **自建中转 / 自有域名**     | 手里有云服务器或域名，想完全自己掌控线路          |            HTTPS            | 见 [自建加密中转指南](/zh/docs/web/relay)，也支持 Cloudflare Tunnel / nginx / frp |

> **安全提醒（很重要）**：页面生成的二维码和复制出来的链接里包含了**登录令牌（相当于你电脑上 Agent 的大门钥匙）**。二维码默认会做模糊遮挡，千万不要把清晰二维码或带令牌的链接截屏发给别人，也不要对外部网络开启 `--no-auth`。

## 网页端有哪些特别顺手的功能？

- **装成手机 App + 实时通知**：在手机浏览器里添加到主屏幕（PWA）后，去「设置 → 通用设置 → 应用与通知」开启推送——Agent 跑完任务、报错或者等你点工具审批时，手机会直接弹系统通知。
- **父子会话树**：用 `#` 派出去的子任务会自动折叠挂在主会话下面，手机小屏上找会话也不乱。
- **划选回复直接追问**：看到 Agent 回复里哪句话有问题，直接用手指或鼠标选中那段文字，点一下就能引用到输入框里接着问。
- **远程看一眼电脑屏幕 / 浏览器**：人在外面想知道电脑桌面上弹了什么窗，可以按需抓一张电脑桌面截图；也可以直接在网页侧边栏实时查看服务器上的浏览器画面。
- **界面扩展插件**：支持安装和开关专门为 Web 端定制的前后端界面插件。
