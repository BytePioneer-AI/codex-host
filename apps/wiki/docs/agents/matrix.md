# 能力矩阵

CodexHost 通过每个 Agent 自己的原生接口（RPC / SDK / ACP）连接。思考深度（Thinking）、权限档位、斜杠命令与上下文压缩都直接映射自该工具本身的原生能力。

- **Edit Diff**：每轮修改文件后，在右侧审查面板汇总展示完整 Diff。
- **工具审批 / 权限模式**：执行命令或修改文件前弹窗确认，或切换会话级权限档位（只读 / 询问 / 自动执行）。
- **`#` 委派**：支持被其他会话通过 `#` 调用，在独立子会话中执行任务。
- **Fork**：从对话中间任意一条消息分叉出新的独立会话。

::: info 说明
`✅` 完整支持 · `◐` 部分支持或有条件限制 · `—` 原生接口暂不支持
:::

## 各工具说明

- **Pi**：Pi 核心不设会话级权限模式档位，因此界面不显示权限模式下拉框；Pi 扩展确认交互正常工作，且在使用支持 Fast 模式的 Codex 模型时输入框会显示 **Fast** 开关。
- **Cursor CLI**：可在 Cursor 会话内向外发起委派，但**不支持作为 `#cursor` 被其他会话后台调用**（团队策略可能静默降级 `--force`，无法保证后台无人值守执行不挂起）。Fork 与编辑上条消息目前支持 macOS 与 Linux。
- **Antigravity (AGY)**：需要 `agy >= 1.5.8`。支持 `default`、`accept-edits`、`auto`、`plan` 权限模式、工具审批与提问卡片；会话空闲时可 Fork。
- **Kimi Code**：可选思考深度（Thinking）随当前模型动态切换；支持退出计划确认卡片与 `#` 委派。
- **Hermes**：通过官方 Hermes Gateway 连接；在未执行过上下文压缩的历史范围内支持 Fork 与编辑上条消息。
- **WorkBuddy 与 ZCode**：需先安装并登录对应的桌面应用（**WorkBuddy Desktop** / **ZCode Desktop**），CodexHost 直接调用其内置 CLI。
