# 定时任务

CodexHost 扩展了 Codex Desktop 内置的定时任务（Automations），支持将本地定时任务指定给外部 Agent、对应模型和本地项目文件夹。

## 创建定时任务

1. 在 Codex Desktop 中打开 **「codexhost 设置 → 定时任务」**，点击新建任务。
2. 展开「高级设置」，开启 **「在此电脑上运行」**，并关闭 **「每次运行都开启新聊天」**。
3. 在弹窗顶部选择 **Agent**（Claude Code、Pi、Grok 等）、**模型** 和 **工作区目录**。
4. 设置执行时间与提示词并保存。

## 限制与说明

- **仅支持本机固定会话模式**：外部 Agent 目前仅支持在本机复用同一个会话运行的个人任务。云端任务、团队任务或「每次运行新建聊天」仍仅支持官方 Codex。
- **侧边栏图标**：绑定外部 Agent 的定时任务会在左侧列表标题旁显示对应 Agent 的图标。
- **需要桌面端保持运行**：定时任务由正在运行的 Codex Desktop 按时触发；电脑休眠或退出 Codex Desktop 期间不会执行。
