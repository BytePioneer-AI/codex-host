# Web 与手机访问

CodexHost 内置独立的浏览器 Web 界面，连接本机同一个后台 Host 进程，占用内存比桌面端更低。只要你的主力电脑开着，就可以从手机、平板或其他电脑的浏览器查看会话、批准工具调用或继续发消息。

## 启动 Web 端

```bash
codexhost web
```

默认监听 `http://127.0.0.1:4400` 并自动打开浏览器。关闭终端窗口或关闭浏览器标签页不会停掉后台 Web 服务，也不会中断正在跑的任务；要彻底停止时运行 `codexhost stop`。

## 从手机或其他设备连接

打开电脑上的 Web 页面，点击左侧栏的 **「远程访问」**（或「设置 → 连接设备」），选择一种连接方式并用手机相机扫码：

| 连接方式 | 适用场景 | 加密方式 | 准备条件 |
| :--- | :--- | :---: | :--- |
| **官方加密中转（推荐）** | 出门在外跨网络连回家里或公司电脑，手机不想装额外 App | HTTPS（在你的电脑上才解密） | 无，直接点「启用中转」即可 |
| **Tailscale HTTPS（推荐）** | 长期跨网络使用，仅允许你自己的设备访问 | HTTPS | 电脑和手机均安装 Tailscale |
| **同一 Wi-Fi（局域网）** | 手机与电脑连在同一个可信路由器下 | 明文 HTTP | 接入同一 Wi-Fi |
| **自建 Relay / 隧道** | 用自己的云服务器和域名托管流量转发 | HTTPS | 见 [自建 Relay](/docs/web/relay)，或使用 Cloudflare Tunnel / nginx / frp |

::: warning 安全注意
**安全注意**：页面上的二维码（默认模糊遮挡）和复制出来的链接里包含**访问令牌（Access Token）**，拿到令牌的人可以直接操作你电脑上的 Agent。请勿把清晰二维码或带令牌的链接发给他人，也不要在非可信网络开启 `--no-auth`。
:::

## Web 与移动端功能

- **手机桌面 PWA 与通知推送**：在手机浏览器将页面「添加到主屏幕」，然后在「设置 → 通用设置 → 应用与通知」中开启推送。任务完成、报错或等待工具审批时，手机会收到系统通知。
- **父子会话折叠**：用 `#` 委派的子任务会自动折叠挂在父会话下方。
- **划词追问**：选中 Agent 回复里的任意文字，点击即可引用到输入框中追问。
- **远程桌面截图与浏览器画面**：在外面时可按需抓一张电脑桌面截图，或在网页右侧栏实时查看服务端浏览器画面。
- **Web UI 插件**：支持安装和开关 Web 界面扩展插件。
