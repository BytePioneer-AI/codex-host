Commands 样式选项

当前按钮用了描边、浅底和 600 字重，高度还比旁边的 Usage / Model 高出 12px，所以会像主按钮。下面这些方案都放在同一条工具栏里，点选后可看实时预览。

高度失衡

Commands 36px，Usage / Model 24px，+ / 麦克风 / 发送 28px。

三重强调

描边 + 填充 + 粗体同时出现，比发送键还抢眼。

语义不清

只有单词 Commands，看不出这是 slash / Harness 命令入口。

圆角不合群

10px 既不像输入框 22px，也不像 Usage 的胶囊。

实时预览

触发器 01 / 现状描边 · 菜单 A / 现状菜单

触发器

点卡片即可选中。推荐先看 02 和 03。

弹出菜单

菜单可以和触发器分开选。现状行高 48px，信息密度偏低。

建议默认：02 工具栏幽灵按钮 + B 紧凑列表 和 Model / Usage 同一视觉层级，Commands 不再像主操作。菜单去掉全大写标题，行高收到 38px。
如果要强调这是 slash 命令：03 保留文字，用 `/` 前缀说明入口，不增加描边。比纯图标更好认。
如果工具栏已经很挤：06 / 07 纯图标 和 +、麦克风对齐。斜杠图标更直白，命令方块更通用；都必须保留 `aria-label` 和 tooltip。
不建议继续用 01 只修圆角或字重不够。只要还是 36px 描边块，它就会压过右边的模型和发送键。
