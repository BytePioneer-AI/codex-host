# 连接设备 · UI 方案 01

[查看深色 UI 图](connect-devices-dark.png)

本目录只有设计评审产物。生成方式为内置 imagegen 工具，遵循 imagegen 技能。业务页面未作修改。

## 设计重点

- 扫码连接：二维码、当前连接方式、连接地址和复制操作放在同一卡片。
- 连接方式：常用方式与其他方式区分，选中态与二维码卡片保持一致。
- 访问管理：中转访问、访问令牌、自动启动分行；身份密钥说明收进详情。
- 停止访问独立放在次要操作区；连接帮助保持折叠。
- 保留当前设置壳体、导航和深色主题，使用细边框与组间留白区分内容。

二维码和地址均为示例。此图用于确认布局与视觉方向。
