# Mobile adaptation · Existing Web palette & Frost

## 原则

**保留现有 Web 主体结构，在会话顶部提供最近访问快捷切换。** 用户仍通过项目侧栏管理 Thread，在同一个会话中看消息、工具、diff 和 Composer；不新增底部 Tab、独立 Thread 首页或另一套设置体系。

当前 Web 源码是主体结构与配色依据，不为移动端引入另一套品牌色调。原型浅色基准对应 `ui-theme/src/styles/design-platform.css`：白色阅读底、近黑正文与原有消息气泡色。磨砂只调整透明度、模糊和深度，不另加暖色 / 蓝色染色或饱和度增强。正式接入必须沿用现有明暗主题，样式限制在移动适配范围；本静态原型只展示浅色，不改生产主题或桌面界面。最近访问是新增交互提案，不冒充现有产品功能，也不改变侧栏「最近更新」的含义。原型不是生产代码，不承诺修改行数或像素级复刻。

## 侧栏：保留入口，紧凑条目

- 会话列表标题行保持「搜索、视图选项、添加工作区」三个独立入口，搜索框按需展开。
- 会话统一 48px 单行，标题 14px / 20px，不在标题下增加状态。右侧按现有 `Rows.tsx` / `StateDot` 表达：运行中是灰色加载指示器，等待交互为状态点加「待审批 / 待回答 / 计划待审」短文案；状态替换时间，而非与时间同时堆叠。触控端与模拟手机预览隐藏普通时间，完整状态与示例时间在可访问名称及会话详情中保留。减少动态时加载指示器静止。
- Host 连接中断不额外映射成任务状态点；保留原有 Composer 连接提示和详情。当前样本未模拟完成未读提醒，不根据“已完成”文字推断未读状态；生产接入须直接复用现有状态投影和组件。
- 保留 Harness 自身图标，取消字母色块徽标与重复 Harness 名称。每行不叠玻璃，选中态使用现有主题的轻量底色。
- 行内「⋯」保留 44px 独立触控区，进入完整标题 / 元数据与操作；与打开会话的链接分离。置顶、归档 / 恢复只改变内存中的样本。返回时恢复到可见触发点；被筛选移除的条目回退到视图选项入口。
- 视图选项在原抽屉内显示，返回后仍是同一个会话列表，不叠加模态框。保留工作区 / 工作区树 / 单列表、手动 / 最近更新、三种归档筛选。控件按即时生效设计；顶部最近访问不随这些选项改变。
- 归档筛选非默认时显示明确提示；搜索遵守当前筛选，可匹配工作区名。详情、搜索与抽屉按层级处理 Escape 和焦点返回。
- 添加的是 Host 电脑上已有目录对应的工作区，不是手机文件夹。原型使用 `/Users/demo/work` 下的固定样本；已有项禁用，选择后明确点击「添加并新建对话」。没有磁盘访问、创建目录或真实 Host 操作。
- 工作区样本、视图偏好和新建会话只保存在页面内存中。真实功能依据为 `WorkspaceBrowser.tsx` 的 `ViewOptionsMenu` 和 `WorkspacePickFlow`；原型的预设手动顺序、目录树和归档内容不代表真实 Host 数据。
- 原抽屉保持 34% 填充与真实背景模糊；条目不再附加材质层，不引入新的色调。

## 最近访问：任务与交互

目标是缩短几个任务之间的往返，而不是把完整侧栏搬到顶部。快捷入口处理「回到刚才的对话」，侧栏处理按项目浏览和寻找更早的会话。

- **入口：** 顶部只有当前标题和最近访问两行，不常驻项目与分支行。最近访问最多提供六个其他会话，单行标题，原生左右滑动；边缘露出下一项，右侧「更多」固定可点。当前会话不重复占一个快捷位。
- **手势：** 横滑只浏览快捷项，不切换会话、不改变访问顺序；点击才切换。使用原生滚动与 proximity scroll snap，支持触摸、触控板及键盘 Tab，不手写拖拽物理。没有无限长标签队列，超过六项到「更多」搜索。标题重复时在快捷项前加入项目名，完整信息仍在选择层。
- **成本：** 标题栏 52px + 快捷栏 48px，合计 100px（不含安全区）。390 / 430px 使用相同结构。零访问记录或只有一个会话不显示快捷行；键盘打开或高度 ≤600px 时隐藏，通过标题继续切换。
- **顺序：** 用户打开已有会话、实际发送并创建新会话时，移到访问记录首位。后台消息、审批状态变化、打开设置和空白新对话不改变顺序。仅在用户完成切换后更新快捷位置。
- **选择层：** 沿用磨砂 sheet；当前会话明确标记，完整标题可换行，显示项目、Harness、任务状态及有无草稿，当前会话还显示分支。搜索标题、项目或 Harness；列表独立滚动，搜索和退出入口不跟着消失。
- **返回：** 切换保存每个会话的草稿、示例附件、模型、工具 / diff 展开状态和阅读位置。选择当前会话只关闭选择层，不回到页首。切换不提交审批、不回答问题、不重发消息，也不迁移 Harness。
- **空态与兜底：** 无访问记录时引导「去侧栏找」；搜索无结果不展示伪造匹配，并保留侧栏入口。不同项目的同名标题由项目与 Harness 辅助辨认。
- **边界：** 示例预置六条访问记录；`?history=empty` / `?history=single` 可验证零 / 单条记录。记录和草稿仅保存在当前页面内存中，刷新重置，不模拟跨设备同步。新建示例使用独立 ID，不覆盖先前的新任务。

现有 Web 的 `ui-workspace/src/client/tree.ts` 使用 `updatedAt` 排序「最近」，`WorkspaceBrowser.tsx` 将该组放在项目分组之后。它回答的是「最近有更新」，不能直接当作这里的「我最近访问过」。本原型没有修改这两处生产实现。

## Composer 能力与底部数据

- **不删能力：** 附件、电脑截图、语音、权限、模型、Harness 和发送仍在输入区域。≤400px 时模型用图标入口，完整模型名通过可访问名称与选择层提供；≤359px 时权限收进「+」菜单，点击目标仍至少 44px，不挤压截图与麦克风。
- **数据语义：** 底部摘要显示最近缓存命中率 CH、输出速度 tok/s 和费用；右侧圆环是上下文已用比例。账号剩余额度是不同的数据，不能与上下文占用混用。点击摘要和圆环分别查看统计与容量。缺失字段隐藏，不补 0；不同示例会话的数据独立。键盘打开时收起底部统计，给输入留空间。
- **示例边界：** 数值全部标为示例，费用示例为公开价格估算，不是实时消费或账单。演示发送不会计算费用或推断 Harness 未提供的数据。
- **电脑截图：** 截的是 Host 所在的 Windows / macOS 电脑，不是手机。原型使用已生成的评审页图片作为示例，演示预览、权限失败、手动重试、附加 / 移除及仅附件发送。附加属于当前 Thread，切换保留；迟到结果不附加到另一个 Thread。真实查看器的放大、旋转和标注不在该原型中模拟。
- **语音：** 当前设备麦克风 + Host 转写是实际能力；原型只用固定文字演示，不调用麦克风、MediaRecorder 或转写服务。录音演示原位接管工具行；「结束并填入」不发送，主发送按钮明确执行「转写并发送」的本地演示。
- **语音保护：** 修改草稿或切换会话后，转写结果不自动覆盖或发送，即使切回原会话也需明确插入。取消（含 Escape）阻止迟到结果；权限失败给出提示和重试。待处理结果未处置时不启动另一段录音。没有模拟长录音撤销、实际设备权限或音频服务重试。

真实依据为 `ui-codexhost/src/client/HostUsageDock.tsx`、`DesktopScreenshot.tsx`、`VoiceInput.tsx` / `voice-input.ts` 和 `ui-conversation/src/client/skeleton/ContextMeter.tsx`。原型不读取账号信息，也不调用这些服务。

## 材质

| Token / 用途 | 值 |
| --- | --- |
| 正文 / 主要按钮 | `#0F1115`，对应 Web 的 primary label / brand primary |
| 页面 / 消息阅读底 | `#FFFFFF`，对应 Web 的 bg base |
| 用户消息气泡 | `#EDF3FE`，对应 Web 的 specific bubble |
| 次级文字 | `#61666B`；磨砂层上使用更深的现有中性色 `#43454A` |
| 分隔线 | `rgba(0,0,0,.10)`，对应 Web 的 border l2 |
| 完成 / additions | `#286548` |
| 等待批准 | `#805516` |
| 错误 / removals | `#A43D36` |
| 默认磨砂 | white 32% / blur `18px`；不增强饱和度 |
| 顶栏 | white 28% / blur `16px`；独立背景层，底部 20px 渐隐 |
| Composer | white 24% / blur `14px`，薄材质 |
| 侧栏 | Web sidebar fill `rgba(249,250,251,.34)` / blur `18px` |
| Sheet | white 46% / blur `22px` |
| 审批 / 问题 | white 48% / blur `20px` |
| 设置大面板 | white 62% / blur `24px`，阅读密集区域更厚 |
| 高光 | 顶缘 1px white 95%，周缘 white 56%，底缘 black 12% |
| Composer 阴影 | `0 12px 32px -8px rgba(0,0,0,.22)` + `0 2px 5px rgba(0,0,0,.06)` |
| 模态遮罩 | `rgba(0,0,0,.12)` |

苹果式磨砂由**低不透明度的现有主题底色 + 真实 backdrop blur + 高光边缘 + 有偏移的中性柔和阴影**组成，不模拟液态折射。大部分背景信息来自真实的下层消息、代码和控件；不加入彩色壁纸、装饰光斑或复制页面来伪造透底。材质表面只使用纵向的微弱高光。

底色不透明度与 blur 分开控制：薄玻璃保留下层色块和软轮廓，大面板提高不透明度与模糊半径以保护阅读。平坦的空白区域不会凭空产生色彩；滚动消息或在 diff 上打开侧栏时，透底变化更明显。

- 顶栏背景独立于前景文字，用遮罩渐隐滚动交界；文字和图标不参与模糊。Composer 保持原来的悬浮输入位置，下方内容经过时可见模糊色形。
- 消息、命令、diff 不透明化为玻璃，优先可读性。
- 不在玻璃 Composer 外再叠一层玻璃底栏。
- 原型有实色对照：同一套 DOM、尺寸和位置，仅去掉材质。
- `prefers-reduced-transparency`、`prefers-contrast: more` 和不支持 blur 的浏览器使用实色。

## 布局与功能位置

| 区域 | 保留的结构 | 手机处理 |
| --- | --- | --- |
| 左侧栏 | 品牌 → 新对话 → 导入 → 会话列表 → 设置 | 340px 抽屉；列表标题行保留搜索 / 视图选项 / 添加工作区，条目保持单行，状态在右侧沿用现有表达；至少露出 40px 会话背景 |
| 会话头 | 侧栏开关 / 新对话 → 标题 → 文件入口 | 标题可打开最近访问；下方为原生横滑快捷栏。项目 / 分支进入选择层，不常驻重复展示 |
| 消息 | 用户消息 → Agent 回答 → 工具活动 / 代码 | 单列 20px 边距，长代码只在局部横滚 |
| Composer | 附件 / 指令、截图、语音、权限、模型、Harness、发送 | 输入 16px，窄屏模型为图标，超窄屏权限可从「+」打开 |
| 底部统计 | 用量摘要、独立上下文圆环 | 单行、可点击详情；缺数据不显示虚假数值 |
| 审批 / 问题 | 接管 Composer | 底部原位面板，不遮罩全会话；详情按需打开 |
| 设置 | 原分类、原浮层 | 分类横向滚动，内容独立纵向滚动 |
| 文件面板 | 原右侧区域 | 从右侧覆盖打开，不另起文件管理页 |
| 新对话 | 欢迎标题、工作区、Composer | 保留居中关系；键盘出现后输入区靠可视区底部 |
| 错误 | 当前会话 + 保留草稿 | 连接提示贴近 Composer，不跳转错误页 |

390 与 430 px 使用同一结构。App 的手机预览最大宽度为 600px；桌面的三栏评审目录不是产品 UI。

## 尺寸与排版

- 系统 sans：Apple system / Segoe UI / PingFang SC；代码使用系统 monospace。
- 会话标题 **14px / 21px，600**；新对话标题 **24px，550**；浮层标题 **18px，600**。
- 消息正文 **14px / 25px**，可切较大字号 16px；输入 **16px / 25.6px**。
- 辅助信息 11–13px，按钮 14px。保留工具式紧凑层级，不引入大标题和营销排版。
- 标题 tracking −.015 至 −.035em；正文接近零。
- 点击目标至少 **44×44px**；主要按钮 **48px** 高。
- 内容边距 20px；浮层边距 22px；Composer 外边距 12px。
- 代码卡 12px，消息 14px，Composer / 审批 / 设置 28px，sheet 顶角 32px。圆角只改变表面轮廓，不移动功能位置。

## 触控与运动

- 按下即背景反馈与轻微缩放，释放才提交；没有 hover-only 操作。
- 抽屉沿 X 轴，sheet 沿 Y 轴；打开与关闭沿同一方向。
- 弹簧：response **0.32 s**、damping ratio **1.0**、mass **1**；`ω = 2π / response`，stiffness `ω²`，damping `2ω`。
- `requestAnimationFrame` 保留实时位置与速度。抓住运动中的面板即可接管；不等待动画结束。
- Sheet grip 和侧栏右缘支持 pointer capture。8px 意图阈值后向关闭方向 1:1 跟随，反方向使用 0.55 阻尼。
- 释放采用 90ms 采样速度，指数减速投影参数 `.998`；投影越过面板 35% 时关闭。
- 关闭按钮、Escape、点击遮罩是等价退出方式。审批不能靠划走来允许或拒绝。
- 减少动态效果时直接落位，取消弹性与缩放；无入场编排或循环装饰动效。

## 平台与状态约束

- `100dvh` 与 `VisualViewport` 跟随浏览器可视区；显式处理安全区、软键盘高度和偏移，不禁用缩放。
- 根页面禁用滚动串联；会话、侧栏、设置内部独立滚动。
- `dialog` 提供模态焦点范围；打开后焦点在标题区域，关闭回到可见触发点。
- 预览状态栏只在 `?preview=1` 出现，非真实 OS 控件。
- Harness 与 Model 独立；已有 Thread 的 Harness 固定。审批只表示单次原生请求，不推出全局权限策略。
- 所有操作仅保存在当前页面内。无上传、外部请求、Host 操作或账号数据。

## 验证边界

源码对照范围与浏览器检查见 README。实色 / 磨砂对照只验证材质不改变布局；真实 iPhone 的软键盘、滚动回弹、辅助技术和性能仍需硬件验证。
