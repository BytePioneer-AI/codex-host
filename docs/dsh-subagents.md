# DeepSeek Harness 原生子智能体

CH 在 DSH `0.1.2-rc.1` 和 `0.1.5-rc.1` 中接入默认的本地 `subagent`、`subagent_fork`，使用 Codex 原生子智能体卡片和只读子会话。其他 DSH 版本仍按既有白名单拒绝。

## 用户可见行为

- 创建子任务时显示其名称、实际运行状态和可验证的模型配置；可进入子会话查看原生输入、可见回答及工具结果。
- 子回答尚未结束时即可读取流式文本。正在执行的工具不被伪装成成功结果。
- 后台启动工具返回成功后，子任务仍可继续运行。父轮结束不停止观察；子任务成功、失败或中断后更新状态和结果。
- 父智能体通过原生 `send_message` 继续同一子任务，或通过 `interrupt_agent` 请求中断。CH 不把中断回执当作执行已停止。
- 取消父 Turn 保留后台子任务；显式关闭普通父 Session 时停止所属子任务并确认原生终态，无法确认时报告失败。关闭只读子详情只释放观察资源。
- 恢复父历史或读取已保存的子会话时保留原生身份；冷读不会向模型发消息。多层子级各自验证直接父身份，通知仅在所属父树中传播。

实时推送由已打开的父 Session 观察器提供；尚未恢复父 Session 时，子详情请求仍重新读取原生快照，不因上次显示运行中而停留在旧内容。来自历史的状态可由后续快照更新，不能覆盖更新的实时状态。

子会话目前只读，后续指令由父智能体的原生工具发送。独立输入框、独立控制按钮和跨 Harness 委派不属于本功能。

## 原生事实与边界

012 使用 `subagents/list` 发现子级；015 同时具有 `subagent/catalog`。子日志的 follow/page 使用原生父子地址，并验证目录、header、descriptor、工作区及所选 profile。完整祖先路径保存在不含凭据的 opaque 句柄中，不把 job ID 当作 Session ID。

原生 catalog 的 `inactive` 只表示当前 driver 未运行。完成、失败与中断根据子级日志实际消费的工作和终态判断；缺少终态时显示观察中断及“执行结果未知”，不制造成功或永久运行。模型与思考档位来自子级自身配置；缺少的字段保持省略，具体展示位置由 Desktop 版本决定。

默认前台委派的工具日志不保证包含子 Session ID。Adapter 优先使用经过目录核实的后台回执；其他关联必须有唯一的任务事实。同名并发不得按返回顺序猜测，无法强关联时保留原生工具并展示独立目录子卡片。

Fork 和 rollback 的继承历史不授予新父会话对旧子级的所有权。历史调用仍可保留，旧父子关系不会被重新绑定成新父拥有的任务。

跨进程 Codex、Claude、ACP 等提供方不保证把内部对话和工具流暴露为本地 DSH 子日志；这些调用保留原生工具输出，不宣称支持缺失的完整内部记录。

观察有界：最多观察 256 个子级、16 层祖先，身份还受公共存储的 1024 字符上限约束；日志和流沿用 DSH Adapter 的事件／字节边界。超出限制或读取失败不等于子任务完成。关闭只读观察只释放订阅，不激活或取消原生工作。

## 验证

自动测试覆盖两版目录／地址解析、所有权拒绝、活动只读快照、子级投影、并发与关闭、公共 Host 状态和后代通知。真实 Gate 使用隔离的 DSH_HOME、真实 CLI 和本地 SSE 模型，不调用计费服务：

```powershell
$env:CODEXHOST_DSH_REAL_COMMAND = '完整路径\dsh.cmd'
node node_modules/vitest/vitest.mjs run --config tests/vitest.config.js tools/gate-dsh/subagents.real.test.mjs
```

两个支持版本分别执行该命令。未设置变量时真实 Gate 跳过，不将跳过算作成功。本功能复用公共 Desktop 协议，未增加专用 Renderer；CLI／Host 协议验证与人工 Desktop 视觉验收分别报告。
