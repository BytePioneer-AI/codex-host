# Claude Code 思考摘要与进度说明

- 实时执行时，Claude Code 发出的每个非空思考摘要增量立即追加到对应的折叠思考项，不等待签名。流中断时保留已显示的摘要，不补发。
- 块结束时，如果签名表明该块是给用户看的进度说明（`narration`），会在外层额外显示一条 `commentary` 消息，不改动折叠思考项。完整 Assistant 消息可以补充签名；同一块最多补发一次。只有完整消息、没有流式增量时，不创建实时思考项。
- 重开历史时，有 `narration` 签名的块仅显示为外层消息；普通可见思考仍显示为折叠思考项。主线程历史保留进度说明占用的思考编号，避免隐藏该折叠项时改变后续普通思考项的编号。
