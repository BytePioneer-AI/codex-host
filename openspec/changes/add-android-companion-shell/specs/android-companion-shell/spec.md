# Spec Delta

## Purpose

为 Android 设备提供免应用商店审核的轻量原生壳，集中管理多台运行 codexhost 的电脑，通过扫码完成安全配对并在贴合原生键盘与导航手势的全屏容器中直接加载对应电脑的会话界面。

## ADDED Requirements

### Requirement: 多主机管理与安全扫码配对

Android 壳 SHALL 维护用户已绑定的电脑列表（名称、访问来源 URL 与加密保存的认证凭据），支持添加、重命名、切换与删除主机。扫码配对 SHALL 解析电脑端连接二维码（包含来源地址与访问令牌），同时支持手动粘贴链接；应用 MUST 先向目标主机验证令牌有效性并在原生安全存储中保存凭据后才登记主机。当目标主机返回认证失效状态时，应用 SHALL 清除失效会话并引导用户重新扫码配对。

#### Scenario: 扫码配对一台新电脑
- **WHEN** 用户使用 Android 壳扫描电脑端展示的 HTTPS 或局域网连接二维码且令牌有效
- **THEN** 应用通过目标主机登录校验并将主机与加密凭据保存至本机列表，随即打开该电脑的会话界面

#### Scenario: 电脑端轮换令牌导致失效
- **WHEN** 已保存的主机在电脑端重新生成了访问令牌，Android 壳再次访问收到认证失败
- **THEN** 应用提示访问令牌已失效并引导用户重新扫码，不在后台无限循环重试

#### Scenario: 删除已保存电脑
- **WHEN** 用户在主机列表中删除某台电脑
- **THEN** 应用移除该条目并清除对应的本地 Cookie 与保存凭据

### Requirement: 传输安全边界

Android 壳 SHALL 优先支持并校验证书有效的 HTTPS 连接（Relay 与 Tailscale HTTPS），不得静默忽略不可信的公网 TLS 证书错误；对明文 HTTP 连接，应用 MUST 仅允许局域网或内网保留地址，拒绝向公网域名或公网 IP 建立明文 HTTP 会话，并在界面明确标注明文局域网连接状态。

#### Scenario: 局域网私有 IP 允许配对并标明状态
- **WHEN** 用户扫描或输入同一 Wi-Fi 下私有地址（如 `http://192.168.x.x:4400`）的连接链接
- **THEN** 应用允许连接，并在主机卡片明确标识当前为未加密的局域网连接

#### Scenario: 拒绝公网明文 HTTP 地址
- **WHEN** 用户扫描或输入非私网的 `http://` 公网域名或公网 IP 地址
- **THEN** 应用拒绝配对并提示必须使用 HTTPS 连接

### Requirement: 受控全屏 WebView 与原生交互补齐

打开选定主机时，Android 壳 SHALL 在受控全屏 WebView 中加载该电脑的会话 Web 界面：通过原生安全区与输入法边距监听保证输入框始终贴合软键盘上沿；拦截系统返回手势优先在网页内回退或收起面板而非直接退出应用；支持原生图片拍照与文件选择器上传附件；仅在应用内打开当前绑定主机的同源页面，其他外部链接 SHALL 转交系统浏览器。遇到网络断开或电脑不可达时，SHALL 展示友好重连与切回主机列表操作。

#### Scenario: 弹出软键盘与上传附件
- **WHEN** 用户在聊天输入框点击输入或点击添加文件附件
- **THEN** 底部输入栏跟随软键盘上移不被遮挡，选择附件时拉起系统相机/相册/文件选择器并正常回传给页面

#### Scenario: 点击外链与断线处理
- **WHEN** 用户在会话中点击第三方文档链接，或目标电脑离线休眠导致加载失败
- **THEN** 第三方外链在系统浏览器打开；页面加载失败时显示带「重试」和「切换电脑」按钮的原生提示页

### Requirement: GitHub Releases 分发与更新检查

Android 壳 MUST 不依赖 Google Play 服务或应用商店运行，可通过独立 APK 安装。应用 SHALL 在主机列表页提供检查更新入口，从公开 GitHub Releases 元数据读取最新版本与已安装版本比较，有新版本时提示用户前往下载并触发系统 APK 安装。

#### Scenario: 检查到新版本 APK
- **WHEN** 用户在主机列表页点击检查更新且仓库存在高于当前版本的已发布 APK
- **THEN** 应用展示新版本号与更新下载入口，方便用户直接下载安装覆盖升级
