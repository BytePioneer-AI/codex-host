# Claude Code Runtime Model Catalog验证结论

## 1. 结论

`add-claude-code-runtime-model-catalog`已完成实现，Hermetic契约、Claude Adapter、Protocol/Host、Renderer、无Prompt真实Catalog Gate和Windows全仓检查均通过。实现使用官方Agent SDK初始化Model列表和稳定`getContextUsage().model`回读，不读取Claude设置文件、不维护静态Claude manifest、不把resolved Model名称当成可重放选择Ref。

本结论不宣布两个不同实际Model的远端可调用性、真实Codex Desktop端到端交互、macOS行为或任意第三方gateway均已验证。对应证据仍按下文标记BLOCKED。

## 2. 实现边界

- Shared Contracts为Catalog entry、Session selection state和external Thread inspection增加严格、可选、display-only的`resolvedModelLabel`；Model控制参数仍只接受opaque `HarnessModelRef`。
- Claude Adapter私有编码`ModelInfo.value`为canonical `claude-model-v1` Ref；`default`解码为省略create Model或`setModel(undefined)`。
- Claude inspection使用`persistSession:false`、空Tool列表和无User Message临时Query；成功结果按normalized cwd进程内缓存，失败不缓存，refresh原子替换。
- create/resume继续lazy。首Turn或显式Existing Thread Model选择才启动长期Query；actual Model readback在Turn或命令完成前进入有序完整state。
- Claude Model setter明确失败时保留旧state；setter后readback无法确认时Session fault。Claude Thinking保持`selectThinkingOption=false`和`unsupported`。
- ModelInfo effort metadata只执行通用shape/transport校验；合法runtime ID原样保留、按Model关联并以ID作为label，不维护Claude-specific allowlist或固定label映射。
- Protocol Core有限支持`codexhost/claude-code-native@<opaque-ref>`；Host不解码Claude identity、不回退Codex/Pi。
- Renderer按external Harness capability复用Model picker，Claude不显示Thinking；alias label与actual display不同时显示紧凑次级actual值。

## 4. 兼容性与降级

当前环境是Agent SDK `0.3.220`，SDK声明配套Claude Code `2.1.220`，实际CLI为`2.1.133`。无PromptCatalog和actual readback实测可用。生产实现不按版本字符串启用能力：

- 初始化缺少Models、Query缺少setter/context operation或旧context响应缺少actual Model时，inspection保持Harness ready但返回空Catalog和`selectModel=false`。
- malformed row、冲突selectable value或非法actual readback返回显式protocol/error结果，不解析description或settings补齐。
- 不因旧CLI可工作就承诺任意历史或未来版本兼容。

## 5. BLOCKED与残余风险

- **真实双Model Live：BLOCKED。** 需要操作者显式设置`CODEXHOST_CLAUDE_LIVE=1`和两个不同、可调用的selectable value；Gate必须证明两个Turn成功且actual Model不同。当前未授权quota，因此没有运行。
- **真实Codex Desktop：BLOCKED。** Hermetic Host和Playwright Renderer Gate通过，但本轮没有受支持Desktop实例、双端点或人工交互环境；未声称真实draft/create、Existing Thread和default reset端到端通过。
- **macOS：BLOCKED。** 本轮全仓和进程清理验证在Windows `win32-x64`执行。
- **第三方gateway差异：BLOCKED。** 当前真实Catalog包含动态配置结果，但报告不记录名称；没有分别对GLM、MiniMax、Bedrock等gateway执行远端Turn或认证Gate。
- Catalog表示Claude Code当前结构化快照，不保证每个row远端可调用；真实Turn错误必须保持显式且不得fallback。
- actual Model名称可能是用户自定义标识，只允许在用户Model UI的有界当前状态中显示，不写日志、Mapping Store或tracked Gate evidence。
