# Tasks

行为验收见 [spec](specs/local-design-preview/spec.md)。与前三个变更无依赖，可以并行。

## 1. 预览服务

- [ ] 1.1 只读静态服务器：根目录限定、工作目录校验、路径穿越与符号链接检查、仅 loopback、无目录列表。验证：越界与穿越用例被拒；相对资源可以加载；非 GET 请求返回 405。
- [ ] 1.2 文件监听与刷新：只向 HTML 响应注入刷新脚本，300 毫秒合并。验证：修改 HTML、CSS 与新增图片后 1 秒内刷新；连续写入只刷新一次；非 HTML 响应内容不变。

## 2. 打开与生命周期

- [ ] 2.1 `preview open|list|show|close` 与控制路由，复用现有本地页面通道打开内置浏览器标签；同一文件复用。验证：真实 Desktop 中打开、切到前台、重复打开复用、关闭标签后可用 `show` 重新打开。
- [ ] 2.2 回退与不支持：没有可见本地任务或内置浏览器时改用系统浏览器；受管远程 Host 返回 `UNSUPPORTED`。验证：分别模拟三种情况并检查返回字段。
- [ ] 2.3 生命周期：Thread 归档与 Runtime 退出时关闭；超出上限时关闭最久未用的预览。验证：归档后 URL 不可访问；退出后端口释放。
