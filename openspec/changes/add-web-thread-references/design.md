# Design

## Context

本变更跨 Web 侧栏与 Composer 两个 UI 包，需要明确拖动所有权，因此保留此短设计。范围和行为见 proposal 与 spec。

- `ui-workspace/src/client/rows/Rows.tsx` 的会话拖动当前依赖排序能力，使用 `effectAllowed = move`，并将 ID 放入 `text/plain`。
- `WorkspaceBrowser.tsx` 存在文档级拖动接受与 dragend 排序处理；仅增加输入框 drop 会造成误排序风险。
- `ui-conversation/src/client/input/editor/runtime.ts` 已提供引用插入和撤销相关入口；`ui-input-trigger` 的引用 codec 区分剪贴板文本与模型序列化，可复用于蓝色行内展示与标准文本传递。
- `packages/web-server/src/ch-sessions.ts` 已通过文本输入转交 Host。CLI 已接受裸 ID、codex 链接及带 Host 的 thread 链接，无须新增读取协议。

## Decisions

1. **拖动是复制引用，不是移动会话。** 侧栏的可引用条件与可排序条件分离，使“最近”等禁止排序的列表仍能提供引用拖动。保留排序负载，另提供带来源的会话引用负载；聊天主区域（含输入框）仅处理符合本地共享 external 归属的引用；区域统一将松开事件交给当前 Composer 的既有引用插入入口，不重复插入。Composer 接收后必须让原排序流程知道此次拖动已由输入消费，dragend 不得提交旧排序标记。跨 UI 包沿用公共交互契约，不直接导入对方内部实现。
2. **蓝色行内展示，标准文本传递。** 复用现有编辑器引用机制，显示蓝色会话图标与标题，不另造卡片系统。引用插入当前编辑位置，无有效位置时追加到末尾；支持与正文混排、整体删除和撤销。引用的剪贴板／草稿文本投影及模型序列化均保留 `[@标题](thread://<id>?hostId=local)`。标题须转义 Markdown 特殊字符和换行，无标题时用短 ID；地址始终使用 canonical ID，不接受任意 HTML。手工粘贴继续走纯文本路径，无网络解析或自动标题查询。消息气泡和队列预览复用既有用户文本投影，将显式会话 Markdown 展示成蓝色会话图标与标题并保留悬停原文；复制消息、历史及队列编辑继续使用未改写的文本，不给会话标签增加点击行为。
3. **菜单复制同一地址。** 受支持会话的既有菜单增加“复制会话链接”，复制 `thread://<id>?hostId=local`，与拖动使用相同地址生成规则。等待剪贴板写入结果后显示成功或失败提示，不新增“复制 ID”菜单项，不打开或读取目标。
4. **不改变执行链路。** 行内引用只序列化为标准链接，不追加引用元数据块或 CLI 提示，不扫描用户正文触发读取。已有 Skill/CLI 承担能力发现和读取；完整链路验证不能仅以蓝色展示正确代替。
5. **不增加独立状态。** 编辑器内复用已有引用数据，草稿恢复沿用现有机制；队列与历史继续使用文本载体，队列编辑回填为标准文本链接即可，不要求重新装饰为蓝色。失败保留当前编辑器草稿与引用。不得新增引用索引、目标内容缓存或可读性快照；引用外观失效时文本投影仍保留完整身份，无迁移需求。

6. **拖入反馈只使用短暂 UI 状态。** 从同页侧栏的原生 dragstart 读取并核对引用来源，供受保护的 dragover 阶段展示；聊天区域按当前编辑器可编辑状态接收。悬停显示覆盖整个可接收区域的浅蓝层、“松开以引用聊天”及会话图标与安全标题预览，不读取历史。覆盖层不参与命中测试，跨内部子元素移动不撤下高亮；离开区域、松开、Escape、dragend、窗口失焦或目标卸载时清理。文件拖动不参与此流程，侧栏排序继续由原拖动所有者负责。

## Risks / Trade-offs

- [引用 drop 意外触发排序或导航] → 覆盖 dragend、越过侧栏后 drop、非排序列表拖入及拖动结束点击行为的浏览器测试。
- [混合目录的 ID 被误当成共享 CH ID] → 使用已有来源归属判断，无法确认时不产生引用负载；不按 ID 外观或 Harness 标题推断。
- [Agent 未加载 Skill 或沙箱无法访问 Runtime] → 不在 UI 假报可读取；实现验收使用真实支持环境确认一次 CLI 读取，失败按现有能力边界报告，不以新工具或提示注入绕过。
- [行内展示与提交身份脱节] → 测试剪贴板投影、发送序列化、草稿恢复及队列回填中的真实 ID 与来源；蓝色只表示引用，不表示已读取。
- [UI 范围扩大] → 仅增加拖入期间的覆盖提示与标题预览、蓝色行内样式及既有菜单中的复制操作，不增加历史预览面板、选择器、点击跳转或跨来源接入。
