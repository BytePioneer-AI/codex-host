# 验证结论

## 结论

截至 2026-07-30，`show-sidebar-thread-agent-icons` 的 Shared Contracts、Mapping Store-only Host ownership route、Renderer fixed client、版本化 sidebar row/Fiber 绑定和 Pi 图标渲染已经完成。

当前受支持 macOS Codex Desktop `26.721.81911` 的隔离真实 Gate 证明：新建 Pi Thread 的当前真实侧栏 row 显示唯一 Pi 图标，图标位于标题前且不影响原生状态与操作区域。完整 external `thread/list` 聚合仍不在本 Change 范围内；导航离开当前 external Thread 后，Desktop 不保证继续列出该映射，这与 active history/Fork Change 的已知非目标一致。

## 实现中发现并关闭的问题

初始设计把 `data-app-action-sidebar-thread-id` 当作 Host Thread ID。真实 Gate 证明它是 Desktop 内部 opaque task key，不能发送给 Host ownership route。最终实现改为版本化结构绑定：

1. 定位 `data-app-action-sidebar-thread-row`；
2. 要求唯一 React Fiber property；
3. 在有界父链中查找 `conversationId`；
4. 只接受 sibling `dataAttributes` 与该 DOM row 的 task-key、host 和 row-marker 完全匹配的候选；
5. 多个相同候选折叠为一个 Host Thread ID，缺失或冲突时 fail closed。

实现不解析 opaque task key，不记录 Host Thread ID，也不从标题、Model Provider、顺序或时间推断 Harness。
