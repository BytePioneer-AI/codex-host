## 真实Gate

- 官方Claude Agent SDK的稳定context operation在一个合成单Turn后返回有效的当前used/window字段对，Adapter在Turn terminal之后发布`session.usage.changed`。
- 受控Codex Desktop实例选择开发开关下的Claude Code后，首个Turn terminal之后出现原生上下文圆圈；DOM无障碍状态报告有限非零百分比，切出再返回Thread后仍可恢复当前圆圈。
- Renderer没有增加第二个Usage控件，Codex专用零值aggregate只作为协议必填carrier，不写回`HostUsage`。

## 剩余边界

- 真实连续多Turn和Compaction后的Claude圆圈更新尚未扩大验证；Hermetic测试已覆盖连续刷新和迟到结果隔离。
