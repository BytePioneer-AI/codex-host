## 已完成事实

- Mapping Store已实现防御性元数据枚举和幂等`setArchived()`；改变状态复用原子替换，no-op不增加Revision。
- Protocol Core已实现当前Thread列表/管理请求有界解码、查询指纹、版本化Host cursor和官方列表响应校验。
- Host Runtime已实现Metadata-only External目录、当前筛选与排序、官方/External双来源分页、内部官方请求关联以及完整失败收敛。
- External Archive/Unarchive先落盘、后响应、再通知；不关闭Session、不取消活动Turn、不修改或删除Native Session。
- External Pin/Git metadata update明确返回unsupported，不回落到官方Codex；官方管理请求继续原帧转发。
- 列表、Archive和Unarchive不打开未加载Adapter，不读取Snapshot，也不保存Prompt、Transcript、Tool输出、Diff、Usage或Codex历史投影。
