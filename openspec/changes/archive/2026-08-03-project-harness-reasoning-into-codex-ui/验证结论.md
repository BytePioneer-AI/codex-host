## 1. 结论

截至 2026-08-02，`project-harness-reasoning-into-codex-ui` 的公共契约、Protocol Core、Pi 和 Claude Code 生产实现及自动化验证已经完成。Desktop `26.727.6591.0` 与 bundled app-server `0.146.0-alpha.9.2` 已证明 Codex 原生 summary lane 能忠实承载 Harness 明确公开的 Reasoning：正文只在 Turn 运行时可见，完成后使用原版 duration-only `Worked for`/`已处理` 展示。

## 2. 已完成证据

### 2.1 Synthetic Desktop Gate

Fake Host 拦截 `thread/start` 和 `turn/start`，未调用模型。Gate 证明：

- content lane 接受协议但正文不可见；summary lane 运行中正文可见；
- 选定 wire shape 为 `reasoning { summary: [], content: [] }`、一次 `summaryPartAdded` index `0`、后续 `summaryTextDelta` index `0`，完成快照为 `summary: [text]`；
- eager 空 Agent Message 会破坏稳定顺序，lazy Agent Message start 保持 Reasoning 在最终答案之前；
- 成功完成后 Reasoning 正文离开 DOM，只保留原版耗时标签；
- 取消和失败后正文及 Turn 控件正确清理；
- Desktop/Fake Host 重启后的真实 `thread/read` 恢复最终答案，不重放 live delta；当前原版 UI 不显示历史 Reasoning 正文不构成失败。

### 2.2 Real Pi/Desktop Gate

受控 Gate 使用隔离 Mapping Store、Pi 配置副本、Native Session、workspace 和 Desktop profile。Pi 初始 Thinking level 为 `max`，并执行一条只读验证命令。脱敏报告证明：

- live Reasoning 在当前用户 Turn 中可见；
- 当前 Turn 投影一个完成的 Reasoning Item 和两个 summary delta；
- Reasoning 顺序早于 Command Execution 和最终 Agent Message；
- 完成后原生耗时标签可见，Reasoning 正文不可见，最终答案保持可见；
- Desktop 重启后最终答案可重新打开；
- 重开后的同一 Thread 可以继续下一 Turn；
- 隔离配置切换到 `off` 后，新 Turn 产生零个 Reasoning Item、无 Reasoning 耗时标签，最终答案正常显示；
- Gate 未保留 Reasoning 文本、Thread/Session ID、认证副本、Native Session 或 Desktop profile；运行前后 Codex global state 哈希一致。

本地脱敏报告位于忽略目录 `.codexhost/reasoning-gate/real-pi-report.local.json`，不作为提交内容。

- 只投影 Pi/Claude 明确提供的 visible thinking；不推断私有完整思维链。
- Claude `redacted_thinking`、signature、encrypted 和未知 block 被忽略。

- Reasoning 不进入 Mapping Store、诊断、跨 Harness 上下文、提交 fixture 或新缓存。
