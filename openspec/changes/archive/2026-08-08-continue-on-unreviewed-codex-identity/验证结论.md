## 已验证事实

### Desktop指纹

Launcher从官方App读取：

```text
platform=macos
bundle_identifier=com.openai.codex
desktop_version=26.803.41515
desktop_build=6321
desktop_asar_integrity=sha256:87a2040084ab073a3a23c8631e059ee79ae8378dc048a18d480cc8603fe1b059
```

ASAR指纹直接读取官方`Info.plist`的`ElectronAsarIntegrity → Resources/app.asar → SHA256`。该值是Electron保护的ASAR header integrity而非整个文件摘要，并受App代码签名保护；该指纹只用于相同warning确认记忆，未参与Controller结构放行。

### 合成未来内部标识

Focused测试使用`FutureTitleService`证明：

```text
必要标题结构通过
→ Main-process Title Policy完成安装
→ ownership与Renderer reload完成
→ Draft Prewarm Policy ready
→ Renderer Adapter ready
→ Controller输出schemaVersion=1的ready + unreviewed-title-service-identity warning
```

同一测试组证明已评审内部标识不产生warning，服务路径、prototype方法或函数结构失败仍拒绝安装。Launcher严格拒绝旧`ready`文本、unknown字段、非法枚举、超长行、缺少换行和空EOF。

执行根目录`npm start`完成完整构建和clean launch，Launcher与Controller使用新单行JSON readiness成功互通，随后发布最小Runtime Descriptor。只读Inspector验证：

当前真实服务类名`nxe`已在评审集合中，因此该build正确走无warning路径。本Gate未提交Prompt、未创建Thread，未记录Transcript、Model值、Thread/Request ID或完整DOM。

### 真实旧版Desktop兼容

从官方macOS appcast下载`26.727.40816`完整ZIP（build`6067`），验证ZIP完整、bundle identifier为`com.openai.codex`、OpenAI Developer ID深度签名有效且Apple notarization通过。离线私有结构检查确认标题服务类名为已评审的`Nye`。

旧版从忽略目录启动，使用独立`--user-data-dir`、随机Inspector/Controller端口、禁用Sparkle更新和独立进程组，未覆盖`/Applications/ChatGPT.app`或读取当前用户数据。真实结果：

```json

  "state": "ready",
  "warnings": [],
  "attachment": "ready",
```

这证明旧版必要标题结构、Title Policy、Renderer reload、Draft Prewarm、Renderer Adapter和Attachment Server可由新Controller完整安装，已评审身份不产生warning。

### 真实未评审身份warning

复制已构建Controller到忽略测试目录，仅在该副本中把当前真实类名`nxe`从已评审集合移除；生产源码、当前安装和正式Bundle未修改。当前官方`26.803.41515`使用独立用户数据启动后返回：

```json
{
  "schemaVersion": 1,
  "state": "ready",
  "warnings": [
    {
      "capability": "title-isolation",
      "reason": "unreviewed-title-service-identity",
      "observedIdentity": "nxe"
    }
  ],
  "attachment": "ready",
  "controllerError": null

```

这证明真实Desktop在只有内部身份未评审时仍完成完整生产安装，不再以空readiness或结构异常退出。隔离实例清理时发现同bundle identifier的Electron `app.quit()`可能同时退出主实例；正常codexhost随后已恢复。后续原生弹窗三操作Gate必须在专用测试会话执行，不与用户主实例并行。
