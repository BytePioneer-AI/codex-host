# Design

## Context

电脑端只在关闭码 4401（签名错误）、4409（被替换）或不支持协议版本时停止重连；TCP 被关闭等其他断线都走已有的随机退避。

## Decisions

- 总 TCP 上限直接设置 `net.Server.maxConnections`，计入电脑、手机和尚未完成 ClientHello 的连接；现有 socket 集合仍只用于关闭服务时释放连接，不新增计数器。
- 上限在创建 Relay 时校验为正整数，CLI 只负责转换与传递。
- 每小时扫描用量表，删除 UTC 日期早于今天且 ID 不在注册表中的记录；清理不读取会重置日期的额度 getter。定时器不保持进程存活，服务关闭时释放。

## Risks / Trade-offs

- 连接满时，同一身份的替换连接也会被拒绝，直到有连接释放。
- 当天离线记录继续占内存；依次换 ID 可重置每日额度，重启会清零。准入与用量恢复可通过注册检查接口提供。

## Migration

不传新参数时保留现有行为。
