# Spec Delta

## ADDED Requirements

### Requirement: 可选连接总数上限

Relay MUST 支持可选正整数参数 `--max-connections`，限制监听端口的 TCP 连接总数；未配置时 MUST 不限制。无效值 MUST 在启动监听前报错。

#### Scenario: 总连接边界

- **WHEN** 已接受的 TCP 连接数达到配置值，又有新连接到达
- **THEN** 新连接直接关闭；计数包含电脑、手机及尚未完成 ClientHello 的连接，已有连接不受影响；名额释放后可再次接入，电脑端自动退避重连而不永久停止

#### Scenario: 未配置或参数无效

- **WHEN** 部署者未配置上限，或传入零、负数、非整数及非数值
- **THEN** 未配置时保留现有行为；无效参数导致启动报错

### Requirement: 用量记录保留与清理

Relay MUST 定期清理早于 UTC 当天且对应电脑当前未注册的用量记录，MUST 保留当天记录和当前已注册电脑的记录。同一身份当天断开后重连 MUST 不清零额度。额度仍只在内存保存，重启会清零；依次更换身份可获得新 ID 的额度，这不构成准入控制。

#### Scenario: 清理过期离线身份

- **WHEN** 清理时存在前一天的离线身份、前一天仍注册的身份和当天已离线身份
- **THEN** 只删除前一天的离线身份记录，其余记录保留；当天重连继续使用原额度
