## 2. Relay

- [x] 2.1 控制地址和注册：为控制地址终止 TLS，`/v1/agent` 升级 WSS 并在其上作 HTTP/2 客户端；挑战、验签、返回主机名；关闭码 4401、4408、4409；design 中的注册校验规则；WebSocket 消息上限 1 MiB；未知版本路径返回 404；同 ID 新注册替换旧连接并关闭其手机连接；25 秒心跳；`SIGHUP` 重新读取证书。验证：集成测试用测试内的假电脑（HTTP/2 服务端跑在 WebSocket 流上）覆盖注册成功、签名无效、签名绑定其他控制地址、公钥或签名长度不符、超时、替换、未知版本、注册前打开流被拒、超过 1 MiB 的消息断开连接、不回应心跳后被强制断开并注销、证书重新加载后新连接使用新证书。心跳间隔在测试中可通过创建 Relay 时的参数缩短，不加命令行参数。
- [x] 2.2 手机连接转发：按 SNI 路由，原样转发包括 ClientHello 在内的全部字节；每条连接一个 `POST /v1/tcp`，带客户端 IP 和端口；两个方向独立结束，异常时两侧都中断；每个 ID 最多 32 条；流窗口 2 MiB、连接窗口 8 MiB；未知 SNI、离线 ID、控制地址以外的非法名字直接关闭。验证：集成测试中手机侧用真实 TLS 客户端，假电脑在进程内终止 TLS 并返回证书；覆盖握手成功且 Relay 拿不到明文、半关闭后响应完整送达、电脑异常中断时手机连接关闭、第 33 条连接被关闭、离线 ID 被关闭、多条慢读手机连接各自缓存不超过 2 MiB 且同时另一条连接的请求仍及时得到响应、单条连接吞吐不低于窗口 64KB 时的数倍（证明窗口生效）。
- [x] 2.3 限速、额度和日志：按 ID、按方向的带宽上限和按 UTC 日的总额度，重连不清零；超额后关闭现有连接、拒绝新连接，只放行 ALPN 恰为 `acme-tls/1` 的连接并限每条 64 KiB、10 秒和每 ID 每小时合计 1 MiB；日志只写注册、注销、替换和超额事件的元数据。验证：测试用很小的速率和额度覆盖吞吐受限、超额关闭和拒绝、另一个 ID 不受影响、重连后计数保留、验证连接放行、单条上限和每小时合计上限；在转发的内容中放入标记字符串，断言日志输出中没有它。
