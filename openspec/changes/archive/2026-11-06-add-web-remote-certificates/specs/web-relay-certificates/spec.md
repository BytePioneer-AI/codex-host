# Spec Delta

## Purpose

电脑为自己的中转地址自动申请和续期浏览器信任的证书，证书私钥和 ACME 账户私钥只在这台电脑上，用户不需要任何操作。

## ADDED Requirements

### Requirement: 自动申请证书

注册成功后，如果没有可用证书，Web SHALL 向证书机构申请，使用 TLS-ALPN-01 验证。可用证书 MUST 同时满足：覆盖当前主机名、处于有效期内、与证书私钥匹配。ACME 账户私钥和证书私钥 MUST 在本机生成，MUST NOT 发送给 Relay 或其他任何一方。申请成功后新证书 SHALL 立即用于手机连接，不重启 Web 或 Host。证书机构默认是 Let's Encrypt 生产环境，可用环境变量 `CODEXHOST_RELAY_ACME_DIRECTORY` 改为其他 ACME 目录。

#### Scenario: 首次开启中转

- **WHEN** 新电脑第一次注册成功
- **THEN** Web 申请证书，完成后手机可以经中转打开页面，Web 和 Host 都没有重启

#### Scenario: 身份密钥更换

- **WHEN** 用户删除身份密钥后重新开启，得到新的主机名
- **THEN** 旧证书和旧主机名的失败记录都不适用，Web 为新主机名申请证书

### Requirement: 续期

证书的实际有效期过去 2/3 后，Web SHALL 续期，续期沿用原证书私钥。Web SHALL 在每次注册成功时检查，注册保持期间每小时检查一次；电脑休眠错过续期时间时，醒来重新注册后 MUST 补做。新证书装好之前 MUST 继续使用仍可用的旧证书；证书到期后 MUST 停止使用。

#### Scenario: 长期运行

- **WHEN** Web 连续运行到证书有效期过去 2/3
- **THEN** Web 在一小时内开始续期，成功后手机连接不中断

#### Scenario: 休眠后醒来

- **WHEN** 电脑休眠跨过了续期时间，醒来后重新注册
- **THEN** Web 立即续期；证书已过期时同样能完成续期，因为验证不需要正式证书

### Requirement: 失败处理

申请失败时，Web SHALL 按递增间隔重试，间隔基准最长 24 小时，随机抖动只能推迟，并且 MUST 不早于证书机构要求的等待时间。下一次尝试时间 MUST 保存到磁盘；重启 Web、重新注册都不提前重试；中途断线或被中止的尝试同样计入。验证连续失败两次，或证书机构因 CAA 记录拒绝签发时，Web MUST 停止自动申请，直到用户重新打开中转开关或 Web 重启；重新打开开关仍须遵守证书机构要求的等待时间。失败分类 MUST 只依据证书机构返回的结构化结果，不解析说明文字。只有当前注册生效的 Web 进程申请证书，注册失效时 MUST 作废进行中的申请。

#### Scenario: 证书机构暂时不可用

- **WHEN** 申请时证书机构返回服务端错误
- **THEN** Web 按递增间隔重试，重启 Web 后仍按保存的时间重试

#### Scenario: 证书机构要求等待

- **WHEN** 证书机构的响应要求一段时间后再试
- **THEN** 下一次尝试不早于该时间，即使用户重新打开中转开关

#### Scenario: 验证一直失败

- **WHEN** 由于 Relay 配置错误，验证连续失败两次
- **THEN** Web 停止申请，连接设备页显示原因，不再消耗证书机构的失败额度

#### Scenario: 被另一台电脑替换

- **WHEN** 申请进行中，这台电脑被同一身份的另一台电脑替换
- **THEN** 这台电脑作废这次申请，不再应答验证，也不再写入证书

### Requirement: 证书文件

ACME 账户私钥、证书私钥和证书 SHALL 保存在数据目录的中转目录中，只有当前用户可读。私钥 MUST 以排他方式创建，已存在时读取而不覆盖。新证书 MUST 先确认可用，再原子替换旧文件；不可用时保留旧证书。

#### Scenario: 写入中途退出

- **WHEN** Web 在写入新证书时被终止
- **THEN** 重启后读到的是完整的旧证书或完整的新证书，不会是残缺文件
