## ADDED Requirements

### Requirement: 地址名与邀请码

还没有从当前中转取得地址时，连接设备页 SHALL 在"codexhost 中转"的启用按钮前提供地址名（可选）和邀请码两个输入框。地址名只接受 4–20 位小写字母和数字；留空表示由中转分配。点击启用时 Web 保存这两项，并在每次注册时提交。取得地址后页面 MUST 不再显示输入框，同一身份之后的注册沿用原地址，不能改名。

#### Scenario: 填写名字和邀请码启用

- **WHEN** 用户填写地址名 `alice` 和有效邀请码后点击启用
- **THEN** 注册成功后连接设备页显示 `https://alice.<域名>`，输入框不再出现

#### Scenario: 名字留空

- **WHEN** 用户只填写邀请码就点击启用
- **THEN** 中转分配地址名，页面显示分配到的地址

#### Scenario: 关闭后再启用

- **WHEN** 已取得地址的用户关闭中转后再次选择 codexhost 中转
- **THEN** 页面不显示输入框，启用后沿用原地址

### Requirement: 注册被拒的处理

中转拒绝注册时，Web SHALL 按原因处理：名字已被占用、邀请码无效、已被停用时 MUST 停止重连并关闭中转，连接设备页在输入框上方显示原因，用户修改后可再次启用；容量已满时 MUST 按重连规则自动重试，页面显示中转已满、正在重试。

#### Scenario: 名字已被占用

- **WHEN** 用户填写的地址名已被其他电脑使用
- **THEN** 中转关闭，页面提示"这个名字已被占用，请换一个"，用户换名字后可以再次启用

#### Scenario: 邀请码无效

- **WHEN** 邀请码不存在或已被其他电脑使用
- **THEN** 中转关闭，页面提示邀请码无效或已被使用

#### Scenario: 容量已满

- **WHEN** 中转因容量已满拒绝注册
- **THEN** 中转保持开启并自动重试，页面显示中转已满、正在重试

### Requirement: 额度用完提示

中转通知当日额度用完时，连接设备页 SHALL 显示今日流量已用完以及恢复时间（下一个 UTC 日），在额度恢复前保持该提示。电脑上的任务和其他连接方式 MUST 不受影响。

#### Scenario: 额度用完

- **WHEN** 中转通知这台电脑的当日额度已用完
- **THEN** 连接设备页显示今日流量已用完和恢复时间，局域网和 Tailscale 访问照常可用

## MODIFIED Requirements

### Requirement: 连接与注册

开启后 Web SHALL 通过 443 端口的出站 WSS 连接控制地址，按 Relay 协议完成注册并记录 Relay 返回的地址。一次连接尝试超过 30 秒未完成注册即放弃并按重连规则重试。环境变量 `HTTPS_PROXY` 指向 HTTP 代理时 MUST 经该代理连接。连接设备页 SHALL 按手机能否访问显示状态：关闭；准备中（连接、注册和首次申请证书）；已开启（附地址）；暂时无法使用（附自动重试时间）；需要处理（证书申请暂停，附证书机构的说明）；已停止（附原因）。准备中时页面 SHALL 自动刷新直到状态稳定。证书有效期、续期和申请过程 MUST NOT 作为单独状态显示。

#### Scenario: 注册成功

- **WHEN** 电脑能访问 Relay，注册通过，证书有效
- **THEN** 连接设备页显示已开启和 `https://<地址名>.<域名>`，不显示证书有效期

#### Scenario: 经代理连接

- **WHEN** 电脑只能通过 HTTP 代理访问外网，`HTTPS_PROXY` 已设置
- **THEN** Web 经代理连上 Relay 并完成注册

#### Scenario: 证书申请失败

- **WHEN** 已注册但证书申请失败
- **THEN** 连接设备页显示暂时无法使用和下次重试时间；申请已暂停时显示需要处理和证书机构的说明
