# Design

## Context

`RelayTls.accept()` 在 TLS 握手成功后将解密 socket 写入 `RequestTrust.relaySockets`，再交给现有 HTTP server；`main.ts` 的 HTTP 与 WebSocket upgrade 均能查询这个标记。当前 `StreamRegistry.attach()` 未携带连接来源，RPC context 只有认证等信息。CH 历史和 `SessionLog` 由所有浏览器共用；Host `truncateToolOutput` 因此不适合作为连接级预览。`TurnProjector.itemCompleted()` 的 `capText()` 已将展示文本限制到 100,000 字符。

## Decisions

- **可信连接属性**：HTTP 和 `/api/remote.mux` upgrade 时以 `trust.relaySockets.has(request.socket)` 捕获只读 relay 属性，显式传入 RPC/stream 上下文；不能根据 `auth.local === false` 推导中转，也不接受客户端请求字段覆盖。该路径同时覆盖官方和自建中转。
- **发送边界转换**：在 Web 所有相关 follow snapshot/resume、历史 page 和已结束回合输出发送路径生成预览，不修改共享 journal、CH Item 或投影缓存。活动回合整体豁免，包括已结束的工具；活动工具投影保持完整。快照（含续传打开帧）和分页共用转换；实时 event 属于活动回合，直接透传，不扫描整个日志。
- **固定参数**：单项全文阈值 `64 * 1024` 字符，开头预览 `8 * 1024` 字符，窗口工具文本预算 `128 * 1024` 字符。从最新记录向旧记录累计实际发送工具文本，返回顺序不变；单项超阈值，或累计加全文超过预算且该输出大于预览长度时，改发预览。预算是选择全文/预览的软预算：最小预览、小结果和活动回合可能超过预算，不丢弃条目。安全切分 Unicode，不裁掉图片或引用元数据。
- **参数理由**：任务提供的 20 个样本中 15 个不受单项 64K 阈值影响，故必须增加窗口约束；128 Ki 可容纳两个上限附近结果或四个约 32 Ki 的结果，后续中型结果缩为 8 Ki。64 Ki→8 Ki 对大项减少至少约 87.5% 文本，保留足够诊断上下文。这些是设计起点，不是本轮实测结论；字节验证使用固定大项和多中项夹具。
- **稳定引用与全文**：引用包含 Session、日志代次、回合、工具条目、输出片段身份与内容版本；版本取现有投影中 `capText()` 后文本的内容指纹。全文与本地连接现有可见内容完全一致，不绕过 100,000 字符展示上限，不回到 CH 原生 Item 重新格式化，不增加持久全文库。日志代次防止重建后的展示坐标误指向其他条目。
- **接口权限**：新增认证 Session 全文读取 RPC，HTTP gate 与同源规则不变；复用 `ChSessions.owner()` 的 external 所有权确认，再在目标当前可见/已加载投影历史中解析精确回合、工具条目与版本。引用不允许传文件路径。不可访问/身份篡改拒绝，版本变化或历史已替换返回 `session/tool-output-stale`，前端提示刷新。现有 token 授权模型是设备访问权限，不另造用户会话 ACL。
- **浏览器数据流**：Session Controller 经 SessionRemotes 和生成的 session/toolOutput 命名空间按引用读取，沿用既有 Remote 编解码与认证路径，并保留当前会话内 Map；键含 Session/Turn/Item/字段/版本，共享在途 Promise 和成功全文，失败删除在途项以便重试。工具组件只调用该能力，locale 提供中英文展开、加载、重试和刷新提示。完整文本不写 journal，不靠修改原生事件触发刷新。
- **展开与复制**：通用、终端、读取及原始检查等实际展示该输出的入口共用全文读取能力；预览与全文都使用正常工具卡片；卡片底部显示带总大小的轻量“显示完整输出”操作，加载及失败维持预览。每个输出只保留一个复制入口，已有卡片复制控件先等待同一全文读取再写剪贴板，不静默复制预览。原位展开复用现有阅读锚点，当前会话内存生命周期结束即释放全文，不自动补全。

## Risks / Trade-offs

- [连接级转换污染共享缓存] → 并行中转/直连测试核对原 journal 与两份输出；不开启 Host 截断选项。
- [引用跨 Thread 泄露或旧版本误命中] → 授权先于解析；版本绑定实际文本，覆盖跨会话、未知身份及历史重写。
- [预览与 UI 衍生展示重复携带全文] → 字节测试检查整个响应，不只检查主文本字段；所有隐藏副本都不能保留全文。
- [续传缓存含已取全文或旧 transient] → 显示缓存与全文 Map 分离，按版本复用，日志换代按权威恢复契约替换。

## Migration

在 `resume-cached-web-session-history` 后实现，保持独立变更与验证。Web 与浏览器须配套更新；没有持久数据迁移。回滚恢复完整发送并刷新页面，无需改写 Host 或原生历史。不要运行用户服务的 start/stop；浏览器验证使用既有隔离 fake Host/Web 测试环境。
