# Proposal

## Why

工具结果占历史窗口传输的主要部分；仅限制单个巨型结果不能降低多个中型结果的总量。中转连接按需读取已结束工具输出，减少首屏流量，同时保留其他连接的完整加载行为。

## What Changes

- 仅官方或自建 codexhost 中转连接接收有界工具输出预览和带版本的稳定引用；活动回合保持完整。
- 同时限制单个输出与每个历史窗口工具文本总量，不新增配置项。
- 提供沿用认证、可见会话授权与版本校验的全文读取接口。
- 工具预览提供中英文“显示完整输出”、加载状态、重试及版本失效刷新提示；复制先取全文，当前会话内复用已取内容。
- 补充服务端和手机浏览器测试、首屏字节对比与截图，更新现行功能文档。

## Decisions

- 以服务端 TLS 终止处登记的真实中转 socket 为依据，不以域名、代理头或远程 IP 猜测。
- 预览是连接级输出表示，不修改共享历史缓存，也不启用 Host 的共享快照截断。
- 使用单项 64 Ki 字符、预览 8 Ki 字符、窗口 128 Ki 字符预算；预算耗尽后仍允许较大结果退为预览，不截断活动回合。
- 全文就是现有投影按 100,000 字符上限裁剪后的文本，与本地可见内容一致；版本使用该文本的内容指纹，不做持久全文副本或后台补全。

## Capabilities

### New Capabilities

- `web-tool-output-loading`: 按连接来源有界展示工具输出，以及带版本的授权全文读取、展开和复制。

### Modified Capabilities

无；中转身份和既有认证规则不变。

## Impact

涉及 Web 连接/RPC 传输、历史输出与投影条目定位，Session Runtime 的日志身份，浏览器 Session Controller、工具 UI 和 locale。公共新增类型保持浏览器安全；不修改 Host→Web 指纹/压缩，不引入新依赖。维护 `docs/product/standalone-web.md` 或 `web-remote-access.md`。
