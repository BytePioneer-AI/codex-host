# Spec Delta

## Purpose

定义工具输出在 Web 中按连接来源进行有界预览、授权全文读取、版本核对和用户主动展开的行为，使中转首屏更轻，同时保持非中转连接和活动回合的现有完整展示语义。

## ADDED Requirements

### Requirement: 仅中转连接启用预览

服务器 MUST 仅对实际经官方或自建 codexhost 中转进入的浏览器连接提供工具结果预览。localhost、局域网、Tailscale、反向代理连接 SHALL 保持现有完整加载行为。连接判定 MUST 来自服务端可信来源，不接受浏览器自报或转发头触发。

#### Scenario: 官方或自建中转
- **WHEN** 同一会话通过真实中转连接读取历史
- **THEN** 符合阈值或预算条件的已结束回合工具输出下发预览和稳定引用

#### Scenario: 非中转连接同时查看
- **WHEN** 中转和非中转浏览器同时读取同一会话，或非中转请求伪造中转相关请求字段
- **THEN** 非中转响应仍包含现有完整工具输出，共享历史不被中转预览修改

### Requirement: 单项阈值与窗口预算

中转历史窗口 SHALL 对已结束回合的工具文本同时应用单项阈值和窗口总量预算；超过单项阈值，或超预算后的其余较大输出，返回开头预览、原始长度和带会话、回合、条目、版本身份的稳定引用。活动回合 MUST NOT 截断，用户消息与 Assistant 正文 MUST NOT 因该预算截断。阈值和预算 SHALL 为常量，不提供配置项。

#### Scenario: 单个大输出
- **WHEN** 已结束回合的一项输出超过单项阈值
- **THEN** 中转响应仅包含其开头预览和引用，不包含隐藏全文

#### Scenario: 多个中型输出
- **WHEN** 多项输出分别未超单项阈值，但完整发送将耗尽窗口预算
- **THEN** 超预算的其余较大输出以预览发送，优先保留最新输出的全文且记录返回顺序不变，不退化为仅检查单项阈值

#### Scenario: 正在运行的回合
- **WHEN** 工具已经结束但所在回合仍在运行，或工具仍在输出
- **THEN** 该回合输出保持完整，后续流与活动投影不被预览预算截断

### Requirement: 全文读取核对权限与版本

全文接口 MUST 沿用现有认证和会话可见性授权，只解析服务端确认属于目标会话的回合与条目。引用不是访问凭据；跨会话引用、不可见目标和未认证请求 MUST 被拒绝。版本不匹配 MUST 返回可识别错误；成功返回现有投影中按 100,000 字符上限裁剪后的文本，与本地连接现有可见内容一致；内容版本 MUST 使用该文本的指纹，不绕过展示上限。

#### Scenario: 合法引用读取全文
- **WHEN** 已认证浏览器请求当前可见会话中版本仍匹配的工具引用
- **THEN** 接口返回与本地连接相同的投影输出，保留现有展示上限及裁剪标记

#### Scenario: 版本已失效
- **WHEN** 引用对应内容被改写或该条目已不属于当前历史
- **THEN** 返回明确的版本失效错误，前端提示刷新，不显示其他版本的内容

#### Scenario: 越权或身份篡改
- **WHEN** 请求未认证、目标会话不可见，或将其他会话/回合/条目拼入引用
- **THEN** 请求被拒绝，不返回任何工具全文

### Requirement: 原地展开与全文复制

预览与全文 SHALL 复用正常工具视图，卡片底部 SHALL 提供 locale 中的中英文“显示完整输出（共 xx KB）”轻量操作、加载状态和失败重试，原地展开且保持阅读锚点。每个输出 MUST 只有一个复制入口；已有复制控件 SHALL 先取全文。复制工具输出 MUST 先取得全文，读取失败时不得把预览当全文复制。已取全文 SHALL 按工具身份与版本在当前会话内存中复用，不重复请求；不持久化、不后台预取。

#### Scenario: 展开、失败和重试
- **WHEN** 用户主动展开预览，首次读取失败后点击重试
- **THEN** 显示加载与可重试错误，成功后原位显示全文，不跳到底部

#### Scenario: 未展开时复制
- **WHEN** 用户直接复制仍显示预览的工具输出
- **THEN** 先取得全文再写入剪贴板；随后展开或再次复制同版本不再请求

#### Scenario: 版本更新
- **WHEN** 同一工具身份出现不同内容版本
- **THEN** 不复用旧版全文，按新引用读取
