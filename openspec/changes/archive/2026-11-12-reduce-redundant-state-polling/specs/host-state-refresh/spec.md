## Purpose

规定共享状态的刷新时机与资源边界，保留 GUI/Web 同步、项目和置顶、状态检测及 GUI 原生 Codex 执行路径。

## ADDED Requirements

### Requirement: 排序变更通过确认快照同步

支持排序事件的入口 SHALL 在订阅后读取初始快照，在 Host 保存排序成功后读取确认快照；正常空闲时不持续查询排序。缺少事件支持的兼容入口 SHALL 保持刷新路径。

#### Scenario: 排序保存和恢复

- **WHEN** 一端成功保存排序，或另一端重连、恢复可见
- **THEN** 支持事件的入口读取 Host 确认的排序；失败写入不作为成功广播

### Requirement: Web 会话与组织状态分别校验

事件模式 SHALL 在首次读取、会话变化、重连及用户刷新时核对完整目录；每 10 秒同步项目和置顶，每 60 秒校验完整目录。中间的组织状态查询 SHALL 复用已确认的会话集合，不重复读取目录分页和所有权。旧 CDP SHALL 保留原目录与历史查询。

#### Scenario: 事件连接空闲

- **WHEN** 连接正常且没有会话变化
- **THEN** 中间的 10 秒周期仅更新项目和置顶，60 秒周期仍能发现漏失通知的目录变化

#### Scenario: 会话和组织状态变化

- **WHEN** 会话开始、结束、创建、归档、恢复或改名
- **THEN** 对应通知及时触发目录读取
- **WHEN** GUI 调整项目或置顶而没有通知
- **THEN** 组织状态查询更新对应视图，执行 cwd 保持不变
- **AND** 查询失败不清空已确认视图

### Requirement: 远程连接查询随页面可见性调度

远程连接页 SHALL 在打开、恢复可见、手动刷新及操作结束时读取状态。稳定状态 30 秒查询，操作、远程更新或检查失败时 5 秒查询。隐藏、离页及销毁 SHALL 取消计划查询，迟到结果不回写退役视图。

#### Scenario: 隐藏与恢复

- **WHEN** 远程连接页不可见
- **THEN** 不产生周期查询
- **WHEN** 恢复可见
- **THEN** 立即合并读取最新状态，再恢复对应周期

#### Scenario: 多台 Host 和操作

- **WHEN** 一台 Host 无法响应，或另一台执行操作
- **THEN** 已响应的 Host 继续显示结果；操作结束核对真实状态，不自动重复写操作

### Requirement: Console 全局状态保持所有页面可用

Console SHALL 在全局状态层调度查询，稳定状态 30 秒，启动中或读取失败时 5 秒。隐藏时暂停周期查询，恢复可见立即读取。离开概览 SHALL NOT 停止其他设置页依赖的 Host 在线检测。停止后 SHALL 清理计划查询和监听，忽略旧生命周期的结果。

#### Scenario: 启动与页面切换

- **WHEN** Console 显示启动中，或用户切到其他设置页
- **THEN** 仍按对应周期检测 Host，启动结果和设置页可用性继续更新

#### Scenario: 隐藏、恢复和停止

- **WHEN** 窗口隐藏后恢复可见
- **THEN** 隐藏期间无周期查询，恢复时立即合并读取
- **WHEN** 状态所有者停止且旧请求返回
- **THEN** 旧请求不更新视图或重新创建定时器

### Requirement: 优化保持执行与恢复边界

本优化 SHALL 保留共享 Host 重连机制、通道心跳、空闲释放、更新进度及委派观察，保持 GUI 原生 Codex 执行和共享 Thread 所有权。状态读取 SHALL NOT 创建新的 Harness Session 或重发写操作。

#### Scenario: 优化查询期间执行任务

- **WHEN** GUI 和 Web 使用同一共享 Thread，且刷新频率发生调整
- **THEN** 任务继续由既有 Host 和 Harness 执行，现有消息、队列和交互语义保持不变
