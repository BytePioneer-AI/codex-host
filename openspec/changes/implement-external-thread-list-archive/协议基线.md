# External Thread 列表与归档协议基线

- 核对日期：2026-08-01
- Codex Desktop：`26.727.6591.0`
- 内置 codex-cli：`0.146.0-alpha.9.2`
- 来源：当前内置 Binary 的 `app-server generate-json-schema` 输出

## 本次支持的请求

### `thread/list`

已知参数：

- `ancestorThreadId: string | null`
- `archived: boolean | null`
- `cursor: string | null`
- `cwd: string | string[] | null`
- `isPinned: boolean | null`
- `limit: uint32 | null`
- `modelProviders: string[] | null`
- `parentThreadId: string | null`
- `searchTerm: string | null`
- `sortDirection: "asc" | "desc" | null`，缺省为 `desc`
- `sortKey: "created_at" | "updated_at" | "recency_at" | null`，缺省为 `created_at`
- `sourceKinds: ThreadSourceKind[] | null`
- `useStateDbOnly: boolean`

响应为 `{ data, nextCursor?, backwardsCursor? }`。`nextCursor` 用于同方向继续；`backwardsCursor` 用于相反方向，并按页首时间戳保留同秒边界。

### `thread/archive`

参数为 `{ threadId: string }`，响应为空对象；成功通知为 `thread/archived { threadId }`。

### `thread/unarchive`

参数为 `{ threadId: string }`，响应为 `{ thread: Thread }`；成功通知为 `thread/unarchived { threadId }`。

### `thread/metadata/update`

参数为 `{ threadId, isPinned?, gitInfo? }`。`gitInfo` 可 patch `branch`、`originUrl` 和 `sha`。响应为 `{ thread: Thread }`。

## 与既有实现相关的差异

- 当前 `Thread` 包含 `isPinned`，缺省为 `false`；External Thread 本次固定投影为 `false`。
- 当前 `Thread` 包含可空 `recencyAt`；External Thread 使用持久化 `updatedAt`。
- 当前 `ThreadStatus` 包含 `notLoaded`；未恢复 Native Session 的 External 列表行使用该状态，并将 `canAcceptDirectInput` 设为 `null`。
- 当前列表支持 Pin 过滤和 `recency_at` 排序，旧 Host 没有对应解码或聚合路径。
- 当前存在 `thread/metadata/update`；External Pin/Git patch 不属于 PRD，本次明确返回 unsupported，不能回落到官方 Codex。
- Schema 没有禁止未来增加字段。无法安全应用的未知列表过滤字段只返回官方结果，不注入 External 行。

## 非目标

本基线不表示支持 External Pin、Git 元数据、Detach、Native Session 删除、正文 Preview 或 Transcript 持久化。协议版本变化后必须重新生成并核对 Schema。
