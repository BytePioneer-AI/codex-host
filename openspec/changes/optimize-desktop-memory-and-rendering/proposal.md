# Proposal

## Why

CodexHost Desktop（Tauri v2 / macOS WKWebView）与 Web 端在长时间多会话使用下存在明显内存膨胀与长对话滚动掉帧：活体观测及受控基准证实，单条 3,120 行长会话即可产生约 14 万 DOM 节点（代码块高亮占 69%）、滚动退化至约 20 fps，16 个会话切换后前端缓存粘滞不回落，65 页 PDF 预览会保留全部离屏画布（+259–476 MiB 图形内存），且 Web Server 对非中转连接始终下发并保留全量历史工具输出。需要在保持原生交互体验与安全边界的前提下，系统性建立前端渲染边界、媒体回收、隐藏节流与多端一致的内存预算。

## What Changes

- **隐藏窗口动画冻结**：桌面窗口隐藏或页面不可见时暂停无限循环装饰动画，恢复可见时立即继续播放，降低后台 CPU 与合成开销。
- **PDF 离屏画布回收**：侧栏 PDF 预览保留每页布局几何，离开视口窗口后释放离屏页面画布图形缓冲并收紧单页光栅像素上限，回滚进入视口时按需重绘。
- **历史长代码块默认折叠与超大块降级**：会话流中已结算的长代码块默认折叠为头部预览并支持一键展开，未展开时复制仍复制完整源码；超过安全阈值的超大代码块跳过语法分词，直接以纯文本等宽渲染。
- **工具输出按需预览扩展至全部连接**：将既有 `web-tool-output-loading` 的已结束回合工具输出预览与按需全文读取能力从「仅中转连接」扩展至本地与所有浏览器连接，并允许 Web Server 释放已翻页历史中的超大完成态工具正文、在请求全文时按版本校验回读；活动回合保持完整展示。
- **前端会话内存字节预算**：为页面内存中的暖会话保留与已释放会话缓存补齐有界字节预算，优先降温最旧或最重会话，淘汰后按正常首屏窗口加载。
- **长对话行壳内容虚拟化与搜索租约**：长会话保留每条消息外层行壳与实测高度，视口外卸载正文渲染；始终钉住流式尾部、当前选区覆盖行、聚焦/跳转目标，并在用户触发页面查找时通过临时租约挂载全量内容以保住原生查找体验。
- **已先行合入本集成分支的零体验副作用基础修复**：2× Retina 边线覆层轻量化、Remote Peer 历史视图 10 分钟空闲退役、Desktop MCP Bridge 客户端关闭超时与独立 SSE 存活清理。

## Decisions

- **保留 WKWebView 壳层与既有语法高亮引擎，优先治理页面 DOM、图形缓冲与缓存边界**：引擎对照实测表明同页下 Chromium 峰值内存反高于 WKWebView，直接解决列表卸载、代码折叠、媒体回收与缓存上限比更换渲染内核、替换高亮库或销毁隐藏窗口收益更高且风险更低。
- **采用「行壳内容虚拟化 + 原生查找临时租约」而非强制替换原生查找**：结合选区、聚焦与尾部钉住策略以及临时全量挂载租约，在大幅削减离屏 DOM 与图形缓冲的同时，完整保留用户熟悉的 `Cmd+F` / 跨行选区 / 选区批注与流式吸底行为。
- **历史工具输出采用「预览 + 原地按需全文读取」而非永久丢弃原文**：相比落库硬截断，复用现有 `session/toolOutput` 版本校验通道既能削减服务端与浏览器双侧内存，又不损失本机排障所需的完整输出。

## Capabilities

### New Capabilities

- `web-long-transcript-rendering`: 长对话视口内容虚拟化（含选区/尾部保护与原生查找租约）、历史长代码块默认折叠与超大块纯文本降级、PDF 离屏画布回收，以及隐藏窗口无限动画暂停。

### Modified Capabilities

- `web-tool-output-loading`: 将已结束回合的工具输出预览与按需全文读取从仅中转连接扩展为所有浏览器连接一致生效，并允许历史页释放冗余全文后按需回读。
- `web-session-history-sync`: 为页面内存中的已释放会话缓存与后台暖会话保留增加有界字节预算，避免大型历史会话叠加造成浏览器内存持续攀升。

## Impact

- 桌面壳层：`apps/desktop-shell/src-tauri/`
- Web UI 前端：`apps/web-ui/packages/client/web/`、`ui-sidebar-documentpreview`、`ui-primitives`、`ui-chat`、`ui-workspace`、`apps/web-ui/packages/api/session-controller/`
- 服务端：`packages/web-server/`、`packages/session-runtime/`（兼容既有协议与认证授权边界，不引入外部新依赖）
