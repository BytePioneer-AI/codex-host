# Spec Delta

## Purpose

定义长会话与侧栏重媒体在桌面壳层和 Web 客户端中的渲染边界、代码块折叠与降级、PDF 离屏画布释放及隐藏窗口动画暂停行为，在降低浏览器图形和通用内存占用的同时守住阅读、选区、查找与复制体验。

## ADDED Requirements

### Requirement: 隐藏窗口暂停无限装饰动画

当桌面主窗口被隐藏，或浏览器页面进入不可见状态时，客户端 SHALL 暂停界面中的无限循环装饰动画以降低后台 CPU 与图层合成开销；窗口或页面恢复可见时，动画 MUST 立即恢复运行且不破坏布局或状态展示。

#### Scenario: 桌面窗口隐藏与恢复

- **WHEN** 用户关闭或隐藏桌面主窗口使窗口进入后台不可见态，随后再次唤出主窗口
- **THEN** 隐藏期间无限循环装饰动画处于暂停状态，恢复显示后动画立即继续运行且界面无闪烁错位

#### Scenario: 浏览器标签页切至后台

- **WHEN** 用户在独立浏览器中将 CodexHost 标签页切至后台后再切回前台
- **THEN** 后台期间无限循环装饰动画暂停，切回前台后自动恢复

### Requirement: PDF 离屏画布按视口回收

侧栏 PDF 预览 SHALL 仅对当前视口及邻近预取窗口内的页面保留光栅画布缓冲；当页面滚出预取窗口时，客户端 MUST 取消未完成的渲染任务并释放其画布图形缓冲，同时保留该页的布局尺寸以防止滚动跳动。单页光栅化像素总量 SHALL 受有界上限约束，不改变页面显示尺寸。

#### Scenario: 滚动长 PDF 后释放离屏页

- **WHEN** 用户打开包含数十页的长 PDF 并从首页滚动至尾部
- **THEN** 远离当前视口的已渲染页面释放画布图形缓冲且保留原有占位高度，滚动位置不跳动

#### Scenario: 回滚已释放的 PDF 页面

- **WHEN** 用户从 PDF 尾部快速回滚到此前已释放缓冲的页面
- **THEN** 该页面重新进入预取窗口后自动重新渲染至清晰状态并保持可复制文本层正常

### Requirement: 历史长代码块默认折叠与超大块降级

会话流中已结算的长代码块超过默认行数阈值时，客户端 SHALL 默认折叠展示开头预览行数并提供展开与收起操作；正在流式输出的代码块 MUST NOT 被自动折叠。无论代码块处于折叠还是展开状态，复制操作 MUST 写入完整源码文本。超过安全字符数或行数上限的超大代码块 SHALL 跳过语法分词，直接以等宽纯文本渲染。

#### Scenario: 历史长代码块折叠与完整复制

- **WHEN** 已结算消息中包含超过默认行数阈值的代码块，用户未展开直接点击复制，随后再点击展开
- **THEN** 初始仅渲染开头预览行与展开控件，复制得到完整源码全文，点击展开后显示全部代码行

#### Scenario: 流式输出中的长代码块

- **WHEN** Assistant 正在流式输出一个超过默认行数阈值的代码块
- **THEN** 流式输出期间该代码块保持完整展开展示，不中途折叠打断阅读

#### Scenario: 超大代码块纯文本降级

- **WHEN** 代码块字符数或行数超过语法高亮安全上限
- **THEN** 该代码块不触发语法分词，直接以等宽纯文本渲染且支持正常复制

### Requirement: 长对话行壳内容虚拟化与交互保护

当会话流已加载条目数超过虚拟化阈值时，客户端 SHALL 保留每条顶级消息的外层行壳与实测占位高度，仅在视口及邻近缓冲区内挂载正文内容，超出缓冲区的条目卸载正文子树以释放 DOM 与图形缓冲。客户端 MUST 始终保持流式尾部条目、当前文本选区覆盖区间内的条目以及当前聚焦或跳转目标条目处于挂载态。

#### Scenario: 长会话滚动释放离屏正文

- **WHEN** 用户打开并滚动包含大量历史条目的长会话
- **THEN** 远离视口的历史条目卸载正文并由外层行壳保留高度，滚回时恢复正文且滚动位置不明显跳动

#### Scenario: 跨行选区与流式输出保护

- **WHEN** 用户在长会话中拖选跨越多条消息的文本，或会话末尾正在流式输出新消息
- **THEN** 选区覆盖的起止及中间条目保持挂载不中断选区，尾部流式消息保持挂载与自动跟随

### Requirement: 原生页面查找临时挂载租约

在启用长对话内容虚拟化时，用户触发浏览器原生页面查找操作 SHALL 激活临时查找租约，将已加载的历史条目全部挂载以便原生查找命中全文；查找结束或超时释放租约后，视口外条目 SHALL 自动恢复卸载态。

#### Scenario: 虚拟化长会话中使用原生查找

- **WHEN** 用户在已虚拟化的长会话中按下页面查找快捷键搜索远端历史文本
- **THEN** 临时租约挂载已加载的历史条目使原生查找能够定位目标，租约释放后视口外条目恢复虚拟化卸载
