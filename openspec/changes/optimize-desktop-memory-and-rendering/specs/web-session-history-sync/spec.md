# Spec Delta

## MODIFIED Requirements

### Requirement: 保持缓存展示与阅读行为

命中缓存时 SHALL 立即显示正文并恢复阅读位置，保留“正在获取最新消息…”状态和同步前历史操作限制。同步失败 SHALL 保留可读内容并允许重试。页面内存中的已释放会话缓存 MUST 同时受最多 8 个会话条目与有界总字节预算约束，后台非运行态暖会话保留亦 SHALL 受有界数量与总字节预算约束，超出预算时优先淘汰最旧或较重非活跃会话且不淘汰当前主视图与运行中会话；淘汰后返回按正常首屏窗口加载。

#### Scenario: 返回时同步较慢

- **WHEN** 缓存已显示但权威恢复响应仍未完成
- **THEN** 阅读、滚动和复制可用，历史相关写操作及分页仍等待同步，响应完成不强制跳到底部

#### Scenario: 多个大型历史会话触发字节预算淘汰

- **WHEN** 用户连续浏览多个包含大量历史记录或展开工具输出的非运行态会话，使缓存估算体积超出字节预算
- **THEN** 即使已释放会话数不足 8 个，最旧的非活跃缓存条目仍被及时淘汰以控制页面内存，再次返回被淘汰会话时按首屏窗口正常加载

#### Scenario: 正在运行或当前查看的会话不被预算淘汰

- **WHEN** 浏览器缓存达到字节预算上限且存在当前正在查看的主视图或仍在运行的后台会话
- **THEN** 淘汰逻辑仅释放已停止且非当前查看的暖会话与已释放缓存，不影响正在运行的会话流式更新与当前阅读视图
