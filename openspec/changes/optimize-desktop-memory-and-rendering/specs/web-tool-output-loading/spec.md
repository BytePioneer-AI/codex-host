# Spec Delta

## REMOVED Requirements

### Requirement: 仅中转连接启用预览

**Reason**: 活体与受控基准表明，本地桌面壳和直连浏览器同样会因历史回合中全量工具输出造成 Web Server 与客户端内存膨胀；预览与按需全文读取现统一扩展至所有浏览器连接。
**Migration**: 原有“非中转连接始终下发完整历史工具输出”行为迁移为由 `全部浏览器连接启用历史工具输出预览` 统一约束；用户仍可通过原地展开或复制按需读取完整输出，活动回合保持完整展示。

## ADDED Requirements

### Requirement: 全部浏览器连接启用历史工具输出预览

服务器 SHALL 对所有浏览器连接（包括本地桌面壳、localhost、局域网、Tailscale、反向代理及中转连接）在读取历史会话时，对已结束回合中超出阈值或预算的工具输出统一提供有界预览与稳定引用，以同时控制服务端与浏览器内存占用。活动回合与非工具正文 MUST 保持现有完整展示行为。

#### Scenario: 本地或桌面壳读取含大工具输出的历史会话

- **WHEN** 本地桌面壳或直连浏览器读取包含大工具输出的已结束回合历史
- **THEN** 超出单项阈值或窗口预算的工具输出以开头预览和稳定引用下发，不把完整大文本推送进初始视图

#### Scenario: 官方或自建中转与本地连接行为一致

- **WHEN** 中转连接与本地连接先后查看同一已结束回合的大工具输出
- **THEN** 两者均按相同阈值与窗口预算获得预览和稳定引用，且均可通过同一全文接口按需读取完整输出

## MODIFIED Requirements

### Requirement: 全文读取核对权限与版本

全文接口 MUST 沿用现有认证和会话可见性授权，只解析服务端确认属于目标会话的回合与条目。引用不是访问凭据；跨会话引用、不可见目标和未认证请求 MUST 被拒绝。服务端 MAY 释放已翻页历史视图中保留的已完成超大工具输出全文以节省内存，在收到合法全文请求时按需向 Host 回读并核对内容版本指纹；版本不匹配 MUST 返回可识别错误；成功返回按 100,000 字符上限裁剪后的权威投影文本。

#### Scenario: 合法引用读取全文

- **WHEN** 已认证浏览器请求当前可见会话中版本仍匹配的工具引用
- **THEN** 接口返回按既有展示上限裁剪后的权威投影输出及裁剪标记

#### Scenario: 历史已释放全文按需回读

- **WHEN** 已认证浏览器请求当前可见会话中版本仍匹配的工具引用，且服务端此前已释放该历史页的冗余全文缓存
- **THEN** 服务端按需向 Host 回读并核对版本指纹，返回与完整投影一致的文本及既有裁剪标记

#### Scenario: 版本已失效

- **WHEN** 引用对应内容被改写或该条目已不属于当前历史
- **THEN** 返回明确的版本失效错误，前端提示刷新，不显示其他版本的内容

#### Scenario: 越权或身份篡改

- **WHEN** 请求未认证、目标会话不可见，或将其他会话/回合/条目拼入引用
- **THEN** 请求被拒绝，不返回任何工具全文
