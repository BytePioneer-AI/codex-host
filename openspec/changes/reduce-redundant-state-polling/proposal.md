## Why

GUI、Web 和 Console 已具备部分事件同步，仍存在重复全量读取和不可见页面的周期查询。减少这些开销，同时保留项目、置顶、断线恢复、状态检测及 GUI 原生 Codex 的现有行为。

## What Changes

已实现的 Harness 排序事件同步继续使用。本轮仅完成三项：

1. **Web 会话目录**：事件模式下，每 10 秒只同步项目和置顶，每 60 秒校验完整目录；首次读取、Thread 变化、重连和用户刷新仍读取完整目录。旧 CDP 保留现有查询。
2. **远程连接设置页**：页面不可见时停止周期查询，恢复可见立即刷新；稳定状态 30 秒，操作或远程更新进行中保持 5 秒。
3. **Console 状态**：全局状态层按窗口可见性和启动状态调度，稳定状态 30 秒、启动或读取失败时 5 秒；保留所有设置页依赖的 Host 在线检测。

共享 Host 重连机制保持不变。心跳、空闲释放、更新进度和委派观察不在范围。

## Capabilities

### New Capabilities

- `host-state-refresh`：共享状态的事件同步、必要校验与页面可见性调度。

### Modified Capabilities

无；保留既有 Thread、设置生命周期与 SSH 操作契约。

## Impact

- `web-server`：拆分会话目录与项目/置顶同步，保留现有 Host 接口。
- `renderer-extension`：远程页面及 Console 全局状态的查询调度。
- 定向回归测试与现有产品文档；不新增依赖或公共协议，不改存储、执行所有权及插件认证逻辑。
