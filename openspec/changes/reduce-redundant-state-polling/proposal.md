## Why

GUI、Web 和 Console 部分状态已由事件触发刷新，仍有定时重复查询，造成持续唤醒；其他查询负责项目归属或健康状态，尚不能直接删除。需要逐项优化刷新时机，同时保持跨端同步、断线恢复和 GUI 原生 Codex 路径。

## What Changes

按以下顺序实施，每项完成自己的测试与文档后再推进下一项：

1. **Harness 排序**：补齐 Host 变更广播，GUI、Web 和 Console 读取确认快照；移除支持事件的入口中的 3 秒排序轮询。
2. **Web 会话目录**：事件模式取消每 10 秒全量重扫会话与所有权；项目归属检查拆开保留，复用已确认的会话目录。
3. **共享 Host 重连**：连接成功后停止 3 秒发现定时器；断开后启动有上限的退避重试。
4. **远程连接设置页**：仅页面打开且窗口可见时检查；稳定状态改为 30 秒，用户操作进行中保持 5 秒。
5. **Console 概览**：仅可见时查询；稳定状态改为 30 秒，启动中保持 5 秒，恢复可见时立即读取一次。

已移除的三类偏好轮询作为前置工作，本提案不重复实现。旧 CDP 的兼容查询、心跳、空闲释放检查、更新进度查询及委派任务观察保留。

## Capabilities

### New Capabilities

- `host-state-refresh`：Host 管理状态的事件刷新、可见性约束及必要查询的资源边界。

### Modified Capabilities

无；现有设置生命周期、Thread 管理及 SSH 执行契约继续适用。

## Impact

- `shared-contracts`、`host-runtime`、`desktop-control`：排序通知公共契约和传输、共享连接恢复。
- `renderer-extension`：排序订阅、远程连接页和 Console 刷新生命周期。
- `web-server`、Web 模型目录：排序事件接入、会话与项目刷新拆分。
- 相关定时器/事件测试及现有功能文档；不新增依赖、不迁移存储、不改队列或 Harness 执行所有权。
